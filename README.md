# Informatica — информатика к ЕНТ

Веб-приложение для подготовки школьников Казахстана к ЕНТ (ҰБТ) по информатике на **русском и казахском**. Короткие уроки в стиле Duolingo: видео, теория, интерактивные задания, решение по фото, ИИ-помощник, статистика и геймификация.

> Статус: **MVP v0.1** — готов первый урок «Двоичная система счисления» и вся платформа вокруг него.

## Что уже есть

- **Урок 1** — 15 шагов: видео с озвучкой (ru/kk), теория с иллюстрациями, 8 типов заданий (выбор, несколько ответов, ввод, «лампочки-биты», лесенка деления, пары, порядок шагов, развёрнутое решение), задания в формате ЕНТ, работа над ошибками, итоговый экран.
- **Решение по фото / на холсте** — ученик решает в тетради и фотографирует, или пишет прямо на экране «в клеточку»; ИИ проверяет каждый шаг.
- **ИИ-помощник «Бит»** — подсказка (без готового ответа), разбор ошибки, свободный чат, фото задачи; знает слабые темы и стиль объяснений ученика, отвечает на его языке.
- **Персонализация** — модель освоения навыков, слабые темы, «память наставника» (ИИ ведёт заметки об ученике; ученик их видит).
- **Тренировка** — бесконечные задания генерируются кодом (без затрат на ИИ), чаще по слабым темам; работа над ошибками.
- **Геймификация** — XP, уровни, серия дней, дневная цель, комбо, 10 достижений, звуки, конфетти.
- **Статистика** — XP за неделю, точность, время, освоение тем, последние ошибки.
- **Конспекты** — открываются после урока + личные заметки + сохранённые ответы ИИ.
- Светлая/тёмная тема, PWA (можно установить на телефон с сайта).

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # вписать OPENAI_API_KEY
npm run dev                  # http://localhost:3000
```

Без ключа OpenAI приложение работает, но ИИ-функции показывают запасные (статические) ответы.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер |
| `npm run build` / `npm start` | production-сборка и запуск |
| `npm test` | юнит-тесты (логика + проверка контента уроков) |
| `npm run typecheck` | проверка типов |
| `npm run lint` | ESLint |
| `npm run e2e` | сквозные тесты в браузере (Playwright; сам собирает и поднимает сервер) |
| `npm run voiceover -- binary-intro` | сгенерировать озвучку видео через OpenAI TTS |
