# Шрифты для картинок превью

`Nunito-ExtraBold.ttf` (800) и `Nunito-Black.ttf` (900) — статичные TTF шрифта Nunito (тот же, что в интерфейсе), с кириллицей
и казахскими буквами (ә ғ қ ң ө ұ ү һ і). Нужны серверу для картинки превью ссылки `/r/<код>` (#72): генератор картинок
не читает variable-шрифты и woff2, которые использует интерфейс. Лицензия — SIL Open Font License 1.1 (`OFL.txt`).
Источник — Google Fonts (Nunito v32).
