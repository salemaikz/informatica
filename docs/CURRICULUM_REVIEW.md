## 1. Что показала сверка

1. **Все 13 тем ЕНТ в курсе есть, но веса перекошены.** НЦТ публикует официальный план теста по разделам: **4 / 10 / 11 / 1 / 7 / 7**. Наш пробный ЕНТ (`examCount` в `src/content/ent-topics.ts`) даёт другое распределение:
   - устройства и сети — **10** заданий вместо 4;
   - таблицы и веб — **3** вместо 7;
   - Python — **8** вместо 11.

   Прогноз балла (`topicWeight`) считается от тех же чисел, поэтому он тоже смещён.
2. **Самые дорогие по баллам пробелы — в «прикладных» темах.** Ниже то, что встречается в официальных демо, а у нас не разобрано (сверено с текстами уроков):
   - Excel: форматы ячеек, ЗАМЕНИТЬ/ПОДСТАВИТЬ, условное форматирование, проверка данных и выпадающий список, «что считается формулой»;
   - SQL: JOIN (в курсе нет ни одного), `ALTER TABLE … ADD`/`DROP COLUMN`, альтернативный ключ, GRANT/REVOKE (EN-демо № 13);
   - Python: распознать сортировку по коду — вставки и быстрая (пузырёк и выбор уже есть в py-7), `find(sub, start, end)` (сейчас только `find(x)`), вложенные циклы, `abs`, `round`;
   - ИИ: нейрон как взвешенная сумма, кластеризация, «где нейросети не применяют» (EN-демо № 8, 12, 21);
   - ПК: GPU и видеопамять, подбор конфигурации (EN-демо № 2);
   - информация: свойства (EN-демо № 7 «актуальность»).
3. **Программа владельца шире курса по «железу» и Python-синтаксису, но вес «железа» в ЕНТ мал.** Устройства, ПО и сети вместе — около 5 заданий из 40. Большая часть «железа» из программы владельца уже есть в pc-1…pc-3: новых уроков не нужно, только расширения pc-1 и pc-2. Python-синтаксис (`dict`, `math`/`random`, вложенные циклы, матрицы, `pass`) добавляем: это самый тяжёлый раздел (11 заданий).
4. **JavaScript в спецификации не назван, но одно задание в официальной демо есть.** Это микротема темы 13: один короткий урок и консоль без DOM (подробно — в п. 2.2).
5. **Практика есть только для Python.** Для HTML/CSS, SQL и Excel ученик сейчас лишь читает. Нужны песочницы: HTML/CSS и SQL дешёвые, Excel — свой движок формул (`docs/specs/sandboxes.md`).
6. **Целиком нет теории:**
   - свойства информации;
   - JOIN и ALTER в SQL;
   - Excel: форматы, условное форматирование, проверка данных;
   - текстовые документы и презентации;
   - модули `math`/`random`, словари, кортежи, множества, матрицы;
   - непозиционные системы счисления (римская);
   - глоссарий НЦТ.

   Остальное («железо», протоколы, криптография, лицензии, VR/AR, блокчейн) есть хотя бы картой-обзором — нужны точечные дополнения, а не новые уроки.

   Уроки ns-1…ns-4 написаны в старом формате: у них нет `entTopics`. ЕНТ-задания у темы есть (28 в `src/content/ent/ns.ts`, привязаны через навыки), но у самих уроков нет финала «ЕНТ-боссы».

По программе владельца — 75 строк, из них 16 повторов (39–54 повторяют 22–37; 55 и 61 называются одинаково, но по месту в списке это разные пункты — Excel и SQL, см. приложение А). **59 уникальных пунктов: 29 П, 23 Ч, 7 Н.** Полностью нет пунктов:

### 2.2 JavaScript — честный ответ

- **В спецификации JavaScript нет.** Названный язык — только Python. Уверенность высокая.
- **В официальной демо EN 2025 есть одно задание** (вопрос 35, соответствие):
  - `var x="Hello"+10+5` → `Hello105`;
  - `var x=10+5+"Hello"` → `15Hello`.

  Проверяется сложение строк и чисел слева направо. В демо RU 2024 и KK 2025 JavaScript нет. В глоссарии НЦТ есть термин «Скрипт». `<script>`, `alert` и `document.write` в официальных материалах не встретились.
- **Вывод:** владелец прав, JavaScript «чуть-чуть есть». Это одна микротема внутри темы 13 «Веб-проектирование», не раздел. Ожидаемый вес — 0–1 задание в варианте.
- **Делаем один короткий урок `web-3-js`:**
  - `<script>`;
  - `var`/`let`, типы;
  - `+` для строк и чисел;
  - `typeof`;
  - `console.log`/`alert`/`document.write` — только узнать и прочитать;
  - простой `if`.

  К уроку — консоль JS без DOM. Приоритет P2.
