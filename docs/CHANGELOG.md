## 2026-10-02 · v0.3.0 — этап 1: фундамент, «живость», помощники, темп игр

### Как делали
- Главная модель: общие контракты (темп игр, уровни, настройки, ключи словаря), банк заданий, интеграция, проверка.
- Исполнители на `sonnet` параллельно (у каждого свои файлы): калькулятор и черновик; анимации, звук и вибрация; 4 игры × 3 темпа.
- Два независимых ревьюера (`sonnet`) нашли реальные ошибки, их исправили:
  - цифры из калькулятора выбирали ответ в уроке;
  - неточное округление больших чисел;
  - потеря рисунка при другом масштабе экрана;
  - двойной тап пропускал разбор ошибки.

### Банк заданий и ЕНТ
- **Уровни A/B/C** у заданий (как в ЕНТ: 50/30/20%). Генераторы выдают задания по уровню.
- Тренировка идёт **от лёгкого к сложному**.
- Новая ловушка уровня C — восьмеричная запись с цифрами 8/9.
- **Оценка «несколько ответов» по правилам ЕНТ** (п. 18): 2/1/0 баллов. Частичный ответ показывается янтарным и даёт половину балла освоения.
- **Банк заданий** (`lib/bank`): задания разных форм (вопрос, утверждение «верно/неверно», пара, короткий ответ) по любому навыку — основа для новых игр и режимов.

### Помощники
- **Панель «Инструменты»** — кнопка в шапке урока, игры и приложения:
  - обычный калькулятор, как на ЕНТ;
  - перевод 2/8/10/16 **с пошаговым решением**: лесенка деления, разложение по степеням, группы разрядов;
  - арифметика в любой системе;
  - единицы информации и время передачи;
  - степени двойки;
  - **черновик** — рисунок и текст, 3 листа, сохраняется в браузере.
- В игре: «Спокойно» — все инструменты, «Обычный» — как на ЕНТ (калькулятор и черновик), «Блиц» — без инструментов.

### Темп мини-игр
- У каждой игры три темпа: **Спокойно** (без таймера, разбор после ошибки, без рекорда), **Обычный** (время по сложности задания, пауза), **Блиц** (на рекорд). Рекорды «Обычного» и «Блица» раздельные, выбор темпа запоминается.
- **Бит-спринт.** Спокойно — 12 вопросов. Обычный — 15 вопросов по 12–28 с. Блиц — бонус времени по сложности (+1,5…3,5 с). Темы открываются постепенно.
- **Битовый тумблер.** В «Спокойно» веса разрядов и сумма всегда на экране. В «Обычном» 25–55 с на задание.
- **Сортировщик.** Вес правила по сложности: на разрядах карточки падают медленнее. Новое правило объявляется заранее. В «Спокойно» карточки не падают.
- **Найди ошибку.** Спокойно — 6 задач без таймеров. Обычный — 8 задач, 31–57 с на поиск.

### «Живость»
- Анимации (`motion`):
  - переходы между шагами урока, пружинящая панель ответа;
  - встряска при ошибке, «всплеск» верного ответа, XP «летит» в счётчик;
  - огонёк комбо;
  - счётчики и поочерёдное появление на итогах;
  - живой маскот (моргает, радуется, грустит);
  - плавная навигация.
- Новые звуки (синтез, без файлов): верно, неверно, комбо, уровень, XP. **Вибрация** на Android.
- В профиле: «Вибрация» и «Меньше анимаций» (плюс системная настройка).

## 2026-10-02 · v0.1.1 — исправления по ревью кода, правило распределения моделей

### Правила
- В CLAUDE.md: **распределение задач между моделями по сложности** (haiku — механика, sonnet — работа по ТЗ, главная модель — архитектура/ТЗ/проверка) и лестница моделей OpenAI в приложении (код → nano → mini → gpt-5.5 только офлайн).
- Курс программирования — Python. Носителя казахского нет → вычитка сильной моделью.

### Исправлено (по независимому ревью кода)
- Холст решения стирался при проверке ИИ (а старая картинка уходила повторно) — холст больше не размонтируется; рисунок экспортируется сразу после штриха (нет гонки «нарисовал → сразу проверить»).
- «Работа над ошибками»: дубли одной ошибки, потеря ссылки на урок → одна запись на задание, урок сохраняется, верный ответ закрывает ошибку.
- API: тело `null` давало 500 → теперь 400; проверка размера картинки до регулярного выражения.
- Заметки: последний ввод терялся при быстром уходе со страницы → сохранение при потере фокуса.
- Лимит ИИ при проверке фото показывал «ошибку связи» → теперь «лимит исчерпан» (+ проверка введённого ответа); неудачные запросы к ИИ возвращают дневной лимит.
- Захардкоженные русские «ИИ» и «ошибок: N» в казахском интерфейсе.
- Генератор «какая запись не двоичная» иногда давал 2–3 варианта вместо 4.
- Enter: не перехватывает кнопки вне задания, игнорирует автоповтор; двойной клик не «проскакивает» экран итогов.
- Пропущенное задание лишает бонуса «без ошибок».
- +4 юнит-теста стора (всего 27).

## 2026-10-02 · v0.1.0 — первый урок и платформа вокруг него

### Сделано
- **Каркас**: Next.js 16 (App Router, Turbopack), React 19, TypeScript, Tailwind 4, Zustand (прогресс в localStorage), PWA-манифест и иконки.
- **Дизайн-система**: токены цветов со строгой семантикой (зелёный — верно, красный — неверно, фиолетовый — ИИ…), светлая и тёмная тема, шрифты Nunito + JetBrains Mono, «объёмные» кнопки, маскот «Бит» (SVG, 5 настроений), звуки через Web Audio, конфетти.
- **i18n**: весь интерфейс на русском и казахском, переключение на лету.
- **Онбординг**: язык → имя → класс → цель → стиль объяснений → дневная цель.
- **Главная**: приветствие, дневная цель, карточка «продолжить», карта курса (5 разделов, 15 уроков; готов 1, остальные «скоро»), слабые темы.
- **Урок 1 «Двоичная система счисления»** — 15 шагов: видео, 3 теории с иллюстрациями, задания всех 8 типов, 2 задания формата ЕНТ, развёрнутое решение по фото/на холсте, конспект.
- **Плеер урока**: проверка с цветной обратной связью, объяснения, комбо, XP, работа над ошибками (повтор ошибочных заданий в конце), выход с подтверждением, клавиатура (Enter, 1–9), итоговый экран с XP/точностью/временем/достижениями/темами/ошибками.
- **Видео** «Как компьютер считает»: Remotion-композиция 1080×1080, 7 сцен, ~75 с, озвучка OpenAI TTS на ru и kk (880 КБ), субтитры, постер.
- **ИИ-помощник** (фиолетовый): подсказка без ответа, разбор ошибки с уточняющими вопросами, чат с фото, сохранение ответов в конспект; проверка решения по фото со списком шагов ✓/✗; отзыв наставника после урока; «память наставника» об ученике (видна ученику, можно удалить).
- **Тренировка**: умная (по слабым темам), по навыку, работа над ошибками; задания генерируются кодом; мини-ЕНТ — заглушка «скоро».
- **Конспекты**: конспект урока, личные заметки (автосохранение), сохранённые ответы ИИ, общие заметки.
- **Прогресс**: XP, уровень, серия, точность, время, уроки; диаграмма XP за 7 дней с линией цели; освоение тем; последние ошибки; что ИИ знает обо мне.
- **Профиль**: имя, язык, класс, цель, стиль, дневная цель, тема, звук, достижения, экспорт данных (JSON), сброс прогресса.
- **Серверная часть ИИ**: `/api/ai/tutor` (стрим), `/api/ai/check-solution` (JSON-схема), `/api/ai/lesson-feedback` (JSON-схема); лимиты по IP, санитизация, лог расхода токенов.
- **Тесты**: 23 юнит-теста (логика, генераторы, валидация контента) + 2 дымовых e2e-теста Playwright (`npm run e2e`). Дополнительно вручную-скриптом прогнаны в Chromium: урок целиком на ru и kk (с фото-решением и отзывом ИИ), тренировки, все страницы, тёмная тема, десктоп.
- **Документация**: CLAUDE.md (правила), README, ARCHITECTURE, DECISIONS, ROADMAP, CONTENT_GUIDE, этот журнал.

### Промпты ИИ (`src/server/prompts.ts`)
- Персона «Бит», ответы на языке ученика, казахская терминология (екілік жүйе, қалдық, ҰБТ…), Unicode вместо LaTeX, короткие ответы для телефона.
- Режимы: `chat` (наводящие вопросы вместо готовых ответов), `hint` (одна подсказка, ответ запрещено называть), `explain` (причина ошибки → решение → совет к ЕНТ).
- Проверка решения: вердикт correct/partial/incorrect/unreadable, шаги ✓/✗, совет.
- Запрет глаголов с родом при обращении к ученику (модель угадывала пол — исправлено и проверено).
- Названия тем в контексте ИИ — на языке ученика (иначе модель вставляла русские слова в казахский ответ).
