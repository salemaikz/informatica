### Игры (этап 4) — теперь 12
- **«Бинго»**: карточка 4 × 4 (или 3 × 3) из коротких верных ответов банка, линии и полная карточка — бонус; вопросы, у которых на карточке может быть несколько верных клеток, исключены.
- **«Шифровка»**: 12 фраз об информатике (ru/kk), верный ответ открывает буквы, «Знаю фразу» — выбор из 4.
- **«Ставка»**: ставка 1–3 на уверенность, в конце «Карта уверенности» с выводом.
- **«Босс-битва»**: босс из 3 самых слабых навыков (имя и иконка по теме ЕНТ), «большой босс недели»; без «проигрыша» — «босс отступил».
- **«Собери решение»**: шаги пошаговых разборов уроков по порядку (разборы с 3–7 шагами); новый тип источника игры `source: "worked"` — подходит к любому уроку с разборами («Игрой» в шторке урока, «к любой теме» в тренировке).
- Варианты ответов во всех уроках и играх показывают разметку (`код`, **жирный**) — раньше были видны «сырые» обратные кавычки (`ChoiceView`, `MultiView`, `MatchView`, `OrderView`); короткие варианты мультивыбора — в две колонки, длинные — в одну.

### Python в браузере (этап 8, облегчённо)
- **Песочница `/python`**: Pyodide 0.29.5 в Web Worker, `input()` через поле ввода, **пошаговое выполнение** (строка, переменные, вывод; ползунок и стрелки), понятные объяснения 25 видов ошибок (ru/kk, с номером строки), 8 примеров по темам курса, `?code=`, «В конспект», редактор с подсветкой, автоотступом и панелью символов для телефона. Бесконечный цикл обрывается через 5 с.
- **Изоляция**: код выполняется в скрытом `iframe sandbox="allow-scripts"` (источник `null`) со строгим CSP (без сети, без eval, загрузчик по хэшу); воркер создаётся из Blob, файлы Pyodide качает страница (работает HTTP-кэш) и передаёт байтами. Код из чужой ссылки `/python?code=…` не может читать IndexedDB/localStorage, вызывать `/api/ai/*` и отправлять данные наружу (проверено в Chromium и Firefox; Safari — проверить на iPhone, нужен Safari 16+).
- В теории, ситуациях и разборах у программ — «Запустить в Python»; в заданиях и на пробном ЕНТ этой ссылки нет (не подсказывать ответ).
- Пункт меню «Python» (компьютер) и карточка в «Тренировке».
- В коде отключены лигатуры шрифта (`==` и `<=` больше не превращаются в «═» и «≤»).

### Как делали
- Главная модель: структура курса (38 новых уроков по 13 темам ЕНТ), типы сцен и заданий ЕНТ, хранилище v2, ТЗ (`docs/specs/content.md`, `wave1.md`, `wave2.md`), интеграция, проверка скриншотами.
- Уроки: на каждый урок — автор (`sonnet`) и строгий ревьюер (`opus`), который **пересчитывает каждый ответ кодом** (Python-программы — запуском `python3`, SQL — в `sqlite3`, логика/формулы — перебором) и сам исправляет методику и казахский. Самопроверка автора — `npx tsx scripts/check-content.ts <урок>`.
- Код: 18 модулей в двух волнах; у каждого исполнитель (`sonnet`, карта курса — `opus`) и ревьюер (`opus`), который исправлял найденные дефекты (ревьюеры нашли и исправили больше 150 реальных ошибок).

### Контент: курс ЕНТ целиком
- **38 новых уроков** (было 4): все 9 разделов и 13 тем спецификации ЕНТ-2026.
  - Раздел 1: восьмеричная и шестнадцатеричная системы, любое основание, двоичная арифметика, единицы информации, количество информации (N = 2ⁱ, I = K·i), кодирование текста, кодирование изображений и звука.
  - Логика: операции, таблицы истинности, логические схемы, законы и упрощение.
  - Python и алгоритмы: блок-схемы, переменные, ветвления, циклы, строки, списки, функции и рекурсия, сортировка/поиск/файлы/графы, «что выведет программа» (контекстные задания).
  - Базы данных: реляционная модель, SELECT, изменение данных и агрегаты.
  - Устройство ПК: устройства, процессор и память, программное обеспечение.
  - Сети: сети, IP/URL/DNS, скорость передачи, информационная безопасность.
  - Таблицы и веб: формулы, ссылки и функции, HTML, CSS.
  - Современные IT: ИИ и облака, IT-стартап, 3D-моделирование. Стратегия ЕНТ.
- У каждого урока: ситуация → объяснение с иллюстрацией → пошаговые разборы (сцена меняется по шагам) → ловушка ЕНТ → решаем вместе → задания A → B → C → задание ЕНТ → шпаргалка. У **каждого** задания — бесплатная подсказка (`hint`) и разбор; у вариантов — «почему неверно» (`whyWrong`).
- **Банки заданий** на каждый навык: генераторы кодом для расчётных тем (бесконечная тренировка, ответы считает код), пулы для тем «на знание».

### Навигация
- **Новая главная и карта курса**: быстрые действия (Продолжить, Повторение, Тест ЕНТ, Теория, Поиск), карточка «Продолжить», прилипающая полоса разделов, у каждого раздела — своя «местность» с декором, извилистая дорога через уроки, маскот у рекомендуемого урока, значки «пора повторить».

- **Все готовые уроки открыты** (свободный режим); «Сдать экстерном» раздел — тест 6–12 заданий, ≥ 80% засчитывает уроки.

### Повторение, XP, серия, цели, напоминания
- **XP за повтор урока**: второй раз ×0,5, дальше ×0,3; бонус «без ошибок» — только за первый раз; плановое повторение (тема «остыла») — ×0,75.
- **Интервальное повторение** 1 → 3 → 7 → 14 → 30 → 60 дней; «Разминка/Повторение» (`/drill?mode=review`).
- **Заморозка серии**: каждые 7 дней подряд — заморозка (не больше двух), она спасает серию при пропуске дня. Не покупается.
- **Цели**: дата ЕНТ и отсчёт, целевой балл из 50, уроков в неделю; **прогноз балла** с интервалом (по освоению тем × вес темы на ЕНТ и по пробникам); план недели — 3 самые весомые слабые темы.
- **Напоминания о серии** без сервера: баннер «Серия под угрозой» на главной, уведомления браузера (пока приложение открыто; на Android с установленным приложением — и когда закрыто, через `periodicSync`), **напоминание в календарь (.ics)** — работает на любом телефоне.

- **ИИ-помощник** (фиолетовый): подсказка без ответа, разбор ошибки с уточняющими вопросами, чат с фото, сохранение ответов в конспект; проверка решения по фото со списком шагов ✓/✗; отзыв наставника после урока; «память наставника» об ученике (видна ученику, можно удалить).
- **Тренировка**: умная (по слабым темам), по навыку, работа над ошибками; задания генерируются кодом; мини-ЕНТ — заглушка «скоро».
- **Конспекты**: конспект урока, личные заметки (автосохранение), сохранённые ответы ИИ, общие заметки.
- **Прогресс**: XP, уровень, серия, точность, время, уроки; диаграмма XP за 7 дней с линией цели; освоение тем; последние ошибки; что ИИ знает обо мне.
- **Профиль**: имя, язык, класс, цель, стиль, дневная цель, тема, звук, достижения, экспорт данных (JSON), сброс прогресса.
- **Серверная часть ИИ**: `/api/ai/tutor` (стрим), `/api/ai/check-solution` (JSON-схема), `/api/ai/lesson-feedback` (JSON-схема); лимиты по IP, санитизация, лог расхода токенов.
- **Тесты**: 23 юнит-теста (логика, генераторы, валидация контента) + 2 дымовых e2e-теста Playwright (`npm run e2e`). Дополнительно вручную-скриптом прогнаны в Chromium: урок целиком на ru и kk (с фото-решением и отзывом ИИ), тренировки, все страницы, тёмная тема, десктоп.
- **Документация**: CLAUDE.md (правила), README, ARCHITECTURE, DECISIONS, ROADMAP, CONTENT_GUIDE, этот журнал.

### Промпты ИИ (`src/server/prompts.ts`)
- Персона «Бит», ответы на языке ученика, казахская терминология (екілік жүйе, қалдық, ҰБТ…), Unicode вместо LaTeX, короткие ответы для телефона.
- Режимы: `chat` (наводящие вопросы вместо готовых ответов), `hint` (одна подсказка, ответ запрещено называть), `explain` (причина ошибки → решение → совет к ЕНТ).
- Проверка решения: вердикт correct/partial/incorrect/unreadable, шаги ✓/✗, совет.
- Запрет глаголов с родом при обращении к ученику (модель угадывала пол — исправлено и проверено).
- Названия тем в контексте ИИ — на языке ученика (иначе модель вставляла русские слова в казахский ответ).
