# Как добавлять уроки

## Принципы урока

- **8–10 минут, 12–15 шагов.** Одна теоретическая карточка = одна мысль. Теория всегда сразу закрепляется 1–3 заданиями.
- **Чередовать типы заданий** — чтобы не было скучно (как в Duolingo). Не больше двух одинаковых типов подряд.
- **У каждого задания — объяснение** (`explanation`). Оно показывается бесплатно при ошибке; ИИ — только дополнительно.
- **Минимум 2 задания в формате ЕНТ** (`ent: true`) и **одно развёрнутое решение** (`solution`) — на фото или на холсте.
- Последняя теоретическая карточка урока превращается в **конспект** (`conspect`) — шпаргалка с лайфхаками к ЕНТ.
- Тон — на «ты», коротко, дружелюбно, без глаголов с родом.

## Шаги по добавлению

1. Создать `src/content/lessons/<id>.ts` по образцу `ns-1-binary.ts`.
2. Зарегистрировать урок в `LESSONS` и поменять его статус на `available` в `UNITS` (`src/content/course.ts`).
3. Новые навыки — в `src/content/skills.ts`; для тренировки — генератор в `src/lib/generators.ts` (иначе навык не будет в «Тренировке»).
4. `npm test` — валидатор контента проверит двуязычность, индексы ответов, уникальность id.
5. Пройти урок в браузере на обоих языках (телефонная ширина).
6. Записать в `docs/CHANGELOG.md`, отметить в `docs/ROADMAP.md`.

## Типы шагов

| type | Для чего | Ключевые поля |
|---|---|---|
| `video` | ролик Remotion | `videoId`, `title` |
| `theory` | карточка теории (markdown) | `title`, `body`, `visual?` |
| `choice` | один верный вариант | `options`, `correct` (индекс) |
| `multi` | несколько верных (как в ЕНТ) | `options`, `correct: number[]` |
| `input` | ввести ответ | `answers` (варианты), `mode: number/binary/text`, `suffix` |
| `bits` | собрать число лампочками-битами | `target`, `bits` |
| `ladder` | перевод делением на 2 с выбором остатков | `number` |
| `match` | соединить пары | `pairs: {left, right}[]` (3–6 пар) |
| `order` | расставить по порядку | `items` — в **правильном** порядке, на экране перемешаются |
| `solution` | развёрнутое решение, проверяет ИИ по фото | `reference` (эталон для ИИ), `answer`, `answerMode` |

Общие поля вопросов: `id` (уникален в уроке), `skill`, `prompt`, `explanation`, `ent?`.
Тексты — `{ ru, kk }`; числа и код можно строкой (`"1011₂"`).

Нормализация ответов (`lib/check.ts`): пробелы, регистр, обозначение основания (`₂`, `(2)`, `_2`) и ведущие нули игнорируются.

## Новый тип интерактива

1. Тип шага — в `src/lib/types.ts`.
2. Ответ и проверка — в `src/lib/evaluate.ts` (`Answer`, `isReady`, `evaluate`, `expectedText`).
3. Компонент — `src/components/lesson/steps/<Name>View.tsx` (пропсы `StepProps`), подключить в `QuestionView` плеера.
4. Валидация — в `tests/validate.ts`. Тесты.

## Видео

1. Сценарий — `src/videos/<id>/script.ts`: сцены с `narration` и `heading` на ru/kk.
2. Композиция — `src/videos/<id>/<Name>.tsx` (Remotion: `Sequence`, `spring`, `interpolate`), регистрация в `src/videos/registry.ts`.
3. Озвучка — `npm run voiceover -- <id>` (нужен `OPENAI_API_KEY`; `--force` перегенерирует). Длительности сцен подтянутся сами.
4. **Проверить озвучку обратной расшифровкой** (`gpt-4o-transcribe`, `language=kk|ru`): TTS иногда «проглатывает» фразы. Если фраза пропала — перегенерировать сцену: `npm run voiceover -- <id> --force --only=kk:<scene>`.
5. Проверить в браузере: синхронизация анимации с голосом, субтитры не перекрывают важное.
6. Озвучку на казахском — дать послушать носителю.
