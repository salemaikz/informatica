## Что мешает текущей пробе

- Удвоение объявляется правилом, но причина не показана. Одного примера 101₂ недостаточно, чтобы проверить понимание.
- Бит и вес разряда смешиваются: один бит имеет два состояния, а вес задаётся его местом в числовой записи.
- Четыре летящих импульса от одной кнопки могут создать ложное представление, что бит физически содержит четыре единицы. Счётчик — учебная модель, это нужно показать явно.
- Паузы одинаковые, сцена долго остаётся общей. Нужны вопрос, действие, реакция и время на ответ.
- При финальном переходе вес 1 перемещался под цифру 0. Исправлено: соответствие 4/2/1 сохраняется. У кухни также исправлены обрезание и перекрытие мерок.
- Milena звучит механически. Владелец предпочитает голос первого урока.

## Точная логика

Бит хранит одно из двух значений: 0 или 1. Два независимых бита дают четыре сочетания: 00, 01, 10, 11. Каждый новый бит удваивает число сочетаний. Это объясняет 2ⁿ возможных состояний.

Для чисел дополнительно вводим позиционную запись. Справа единицы. После 1 доступные цифры заканчиваются: две единицы заменяем одной двойкой. Справа пишем 0, в соседнем месте слева — 1, получаем 10₂ = 2₁₀. Затем 11₂ = 3₁₀. При добавлении ещё одной единицы две единицы становятся двойкой, а две двойки — одной четвёркой: 100₂ = 4₁₀. Поэтому веса справа налево — 1, 2, 4, 8, то есть 2⁰, 2¹, 2², 2³. Формула появляется после наблюдаемого переноса.

Не путать: вес позиции 2ⁱ, число сочетаний n битов 2ⁿ и максимальное беззнаковое число 2ⁿ − 1. Три бита дают восемь сочетаний, которыми можно записать числа от 0 до 7. [Методическое объяснение CS Unplugged](https://www.csunplugged.org/en/topics/binary-numbers/how-binary-digits-work/).

## Следующая проба: «Как записать пять нулями и единицами?»

Ориентир 70–90 секунд, одна мастерская и один постоянный ряд позиций. Начальный вопрос: «Как компьютер хранит число пять, если у него есть только “да” и “нет”?» Бит пытается добавить цифру 2; пульт показывает, что доступны только 0 и 1. Дальше это становится опытом, а не лекцией.

1. **Два состояния.** Одна кнопка: выключено/включено → 0/1 → название «бит».
2. **Бытовой пример.** Два переключателя настроек — звук и тёмная тема. Перебрать четыре сочетания; второй переключатель удваивает возможности. Пока не присваивать им числовые веса.
3. **Двоичный счёт.** Учебный числовой дисплей: 0 → 1 → 10 → 11 → 100. Каждый перенос виден; обычное число рядом обновляется 0, 1, 2, 3, 4.
4. **Правило из действия.** Под теми же местами появляются 1, 2, 4; ниже — 2⁰, 2¹, 2². Пояснить: 2⁰ = 1, каждый шаг влево умножает вес на 2.
5. **Первое число.** 101₂: 4 + 0 + 1 = 5. Нулевое место не исчезает.
6. **Второе число.** Переключить младшую и среднюю позиции: 110₂ = 4 + 2 + 0 = 6. Те же веса и расположение.
7. **Проверка.** «А если включить все три позиции — 111₂?» Пауза 3 секунды, затем 4 + 2 + 1 = 7. Вернуться к исходному вопросу.

Количество сочетаний показано на двух битах; диапазон 0–7 — короткая дополнительная карточка после основного ролика, если темп позволяет. Байты, отрицательные числа и устройство процессора сюда не добавлять.

## Голос и анимация

Для первой версии урока в `scripts/generate-voiceover.mts` настроен OpenAI TTS: по умолчанию `gpt-4o-mini-tts`, `coral`, инструкция говорить тепло и чётко. MP3 первого урока уже в репозитории. Настройки окружения фактической генерации не записаны отдельно, поэтому точный голос проверяем по исходному пайплайну; Milena для следующей пробы не используем. Новые реплики после генерации проверяем обратной расшифровкой.

Вначале утверждается речь; ключевые слова получают временные отметки, затем анимация. Один жест — один смысл. Разряды сохраняют координаты; камера не обрезает соседние места. Предметы не закрывают цифры. Итог появляется после действия и остаётся видимым. Звуковые щелчки помогают замечать переключения; фоновая музыка не перекрывает объяснение. В конце проверяем скорость на телефоне и без звука с субтитрами.
