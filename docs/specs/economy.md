# ТЗ: экономика (сердечки, чипы, магазин, тарифы), история тестов, школьная программа

> Этап «v0.6». Запрос пользователя (2026-10-02): сердечки/энергия на день; ИИ за заработанный опыт или валюту; продавать сердечки, валюту и множитель валюты; окно со всем этим; в начале — окно подписки: «Лайт» 1 290 ₸, «Безлимит» (ИИ и уроки без ограничений по сердечкам) 2 590 ₸, на год — 9 990 ₸ и 19 990 ₸; оплата может пока не работать, но всё должно быть и красиво оформлено. Плюс история тестов и работа над ошибками (в том числе по ЕНТ) и выбор «ЕНТ / школьная программа по информатике».

## 1. Правила для всех исполнителей

- Работаете **только в своих файлах** (список в вашем разделе). Чужие файлы не трогать; если без правки чужого файла никак — опишите нужную правку в итоговом отчёте.
- Строки — только через `t("ключ")` из своего файла словаря (`src/i18n/parts/<ваш>.ts`, префикс ключей — ваш). Каждый ключ `{ ru, kk }`. Казахский — литературный, термины НЦТ (`docs/ENT.md`, раздел 4); ЕНТ по-казахски — ҰБТ; без глаголов с родом.
- Валюта называется **«чипы»** (kk «чиптер», ед. «чип»), иконка `Cpu` из lucide, цвет `gold` (`text-gold`, `bg-gold-soft`, текст на золотом — `text-warning-strong`). Сердечки — иконка `Heart` (с `fill="currentColor"`), цвет `heart`. Тарифы: **«Лайт»** (kk «Лайт») и **«Безлимит»** (kk «Шексіз»).
- Никаких эмодзи; иконки — `lucide-react`. Цвета — только токены. Классы — через `cn()`. Ссылка-кнопка — `ButtonLink`. Модальные окна — `Modal` (`src/components/ui/Modal.tsx`). Готовые элементы: `Button`, `Card`, `Pill`, `ProgressBar`, `Segmented/Row/Switch` (`src/components/goals/controls.tsx`), `Mascot/MascotSays`.
- Мобильная вёрстка 360–430 px в первую очередь, крупные кнопки, светлая и тёмная тема.
- React 19: нельзя синхронно вызывать `setState` в эффектах; время в рендере — только через `useNow()` (не `Date.now()`).
- Проверки своей работы (НЕ запускать `npm run build`, `npm run typecheck`, dev-сервер — параллельно работают другие исполнители):
  - `npx tsc --noEmit` — смотреть только ошибки в своих файлах;
  - `npx eslint <свои файлы>`;
  - `npx vitest run <свои тесты>`.
- Итоговый отчёт: список файлов, что сделано, какие ключи словаря добавлены, что не получилось, нужные правки в чужих файлах.

## 2. E1 — Магазин и значки в шапке

**Файлы:** `src/app/(main)/shop/page.tsx`, `src/components/economy/*` (кроме `OutOfHearts.tsx`, `AiCost.tsx`, `NoChipsNotice.tsx`, `HeartsBar.tsx`, `useEconomy.ts`), `src/i18n/parts/economy.ts` (ключ `economy.noChips` оставить), тест `tests/shop-ui.test.ts` (если есть чистые помощники).

**Страница `/shop` «Магазин»** (внутри оболочки приложения):
1. Сверху — карточка баланса: чипы (крупно), сердечки `count/max` или «Безлимит», таймер «следующее через 1 ч 20 мин» / «полный запас», активный бустер «×2 ещё 12 мин», итоговый множитель чипов.
2. Баннер тарифа: бесплатный — золотая карточка «Безлимит: ИИ и уроки без ограничений» → `/plans` (и «7 дней бесплатно», если `canStartTrial`); платный — «Твой тариф: … · ещё N дней» → `/plans`.
3. «Сердечки»: товары `heart-1`, `hearts-full` из `SHOP_ITEMS` за чипы; покупка — `useApp.getState().buy(id)`; недоступно — понятная причина (запас полный / безлимит / не хватает N чипов). Строка «Бесплатно: пройди тренировку — вернёт сердечко» → `/practice`.
4. «Множитель чипов»: `boost-15`, `boost-60` за чипы; `BOOST_PACKS` за ₸ → `ComingSoonSheet`.
5. «Чипы»: `CHIP_PACKS` за ₸ с бейджами «популярный» / «выгодно» → `ComingSoonSheet`.
6. «Как заработать чипы»: 5 XP = 1 чип; урок +5; без ошибок +5; дневная цель +15; достижение +20; пробный ЕНТ +10; множитель тарифа и бустера (значения брать из `CHIP_BONUS`, `CHIPS_PER_XP`, `PLAN_FEATURES`).
7. «ИИ-помощник»: «Сегодня бесплатно: осталось N из M» (`aiFreeLeft`, при безлимите — «без ограничений»); цены сверх бесплатного из `AI_COST` (подсказка, разбор, вопрос Биту, сообщение в чате, проверка фото, разбор пробного ЕНТ; отзыв после урока — бесплатно).
8. «История чипов»: последние записи `ledger` (причина словами, + зелёным / − обычным, дата), свёрнуто до 5, кнопка «ещё».
- Покупка: короткая анимация (motion) и звук `feedback("xp")` из `@/lib/feedback`; ошибка — встряска (`Shake`).

**Значки для шапки** (экспортировать; в `AppShell` их подключит главная модель): `HeartsChip` (сердечко + число или ∞, при 0 — пульсирует; ссылка на `/shop`) и `ChipsChip` (чип + число, рост «подпрыгивает» как `XpChipAnimated`; ссылка на `/shop`). Компактные: оба вместе ≤ 120 px на ширине 360.

## 4. E3 — История тестов и работа над ошибками

**Файлы:** `src/app/(main)/history/page.tsx`, `src/app/(main)/history/[id]/page.tsx`, `src/components/history/*`, `src/lib/ent-steps.ts` (+ `tests/ent-steps.test.ts`), `src/lib/drill.ts`, `src/app/drill/*`, `src/components/exam/ExamRun.tsx`, `src/app/(main)/practice/page.tsx`, `src/app/(main)/stats/page.tsx`, `src/i18n/parts/history.ts`, тесты `tests/history-redo.test.ts`.

1. **`src/lib/ent-steps.ts`** (чистая логика, тесты):
   - `entStepFromRef(ref: string): QuestionStep | undefined` — ссылки «ent:<id>» и «ent:<id>:<n>» → задание для `LessonPlayer`; **id шага = ref**. single → `choice`, multi → `multi`, match с n → `choice` (условие + пункт n, варианты — `choices`, верный — `answer[n]`), context с n → `choice` (общий текст + вопрос n). Уровень, навык, `ent: true`, объяснение — из задания.
   - `examWrongItems(paper, answers, lang): WrongItem[]` — неверные и частично верные ответы попытки пробного ЕНТ (пропущенные не включать) со `stepId` = ref; для соответствия — по неверным пунктам; для контекстного — по вопросам.
2. **`ExamRun.tsx`**: при завершении `recordExam(buildSummary(...), skillScoresOf(...), examWrongItems(...))`. Ошибки ЕНТ так попадают в общую «работу над ошибками» и в историю.
3. **`drill.ts`**: `buildMistakes` понимает «ent:…» (через `entStepFromRef`); новый режим `"history"` в `DrillMode`/`parseDrillMode`; `buildHistoryRedo(entry, stats, seed)` — задания по `openWrong(entry)` (исходный шаг урока → «ent:» → свежее задание банка по навыку), `map` id задания → stepId ошибки.
4. **`DrillScreen` / `drill/page.tsx`**: режим `history` с параметром `entry`; во все режимы передавать `mode` в `LessonPlayer` (проп уже есть). Пустой набор — понятный экран.
5. **`/history` «История тестов»**: плитки (тестов, средний результат, ошибок к исправлению), большая кнопка «Работа над ошибками (N)» → `/drill?mode=mistakes`, фильтры (Все / Уроки / Тренировки / Пробный ЕНТ / С ошибками), список по дням: иконка вида, заголовок (у пробного ЕНТ заголовок пустой — писать по `mode`: «Пробный ЕНТ · мини/полный/по теме»; у тренировки — по `mode`, если заголовок пуст), время, результат «8 / 10» или «32 / 50 баллов», полоска цвета (зелёный ≥ 80%, янтарный 50–79%, красный < 50%), «ошибок 3 · исправлено 1».
6. **`/history/[id]`**: итог, список ошибок (условие, «твой ответ» красным, «верно» зелёным; исправленные — с галочкой), кнопка «Исправить ошибки этого теста (N)» → `/drill?mode=history&entry=<id>`; пробный ЕНТ — «Открыть разбор» → `/exam/result/<examId>`; урок — «Пройти снова».
7. **`/practice`**: карточка «История тестов» → `/history` (рядом с «Работой над ошибками»). **`/stats`**: карточка с итогами истории и ссылкой.

## 6. E5 — Сердечки в уроке и цена ИИ на кнопках

**Файлы:** `src/components/lesson/LessonPlayer.tsx`, `src/components/lesson/Results.tsx`, `src/components/lesson/steps/SolutionView.tsx`, `src/app/lesson/[id]/*`, `src/components/economy/{OutOfHearts,AiCost,NoChipsNotice,HeartsBar}.tsx`, `src/components/ai/*`, `src/app/(main)/tutor/page.tsx`, `src/components/exam/ExamResult.tsx`, `src/components/theory/TheoryReader.tsx` (только если нужно), `src/i18n/parts/hearts.ts` (префиксы `hearts.`, `aicost.`).

1. **Сердечки в уроке** (только `kind === "lesson"`, в тренировке их нет):
   - В шапке плеера — `HeartsBar` (сердечко + число, ∞ при безлимите).
   - Ошибка с первой попытки (`!item.retry`) → `loseHeart()`; анимация потери («−1», сердечко трескается/встряхивается).
   - Сердечек 0, а впереди ещё задания → по «Продолжить» открывается `OutOfHearts` (вместо следующего шага): «Полный запас за 150 чипов», «+1 за 40» (цены из `SHOP_ITEMS`; не хватает — кнопка неактивна, «не хватает N»), «Тренировка вернёт сердечко» → `/practice`, «Безлимит» → `/plans?from=hearts`, «Выйти из урока». Купил — окно закрывается, урок продолжается. Теория и разборы не блокируются.
   - `LessonScreen`: если сердечек 0 (и не безлимит) — вместо плеера полноэкранный `OutOfHearts` с таймером до следующего сердечка.
2. **Итоги** (`Results`): «+N чипов» за сессию (разница `wallet.earned` с начала сессии — запомнить при монтировании плеера) и у тренировки «+1 сердечко» (`finishSession` возвращает `heart`).
3. **Цена ИИ на кнопках** — `AiCost kind`: «бесплатно · осталось N» / «∞» при безлимите / «10» с иконкой чипа, когда платится чипами (`useAiQuote`). На кнопках: ещё подсказка и подробный разбор (`AiPanel`), отправка в чате (`tutor`), проверка фото (`SolutionView`), ИИ-разбор пробного ЕНТ (`ExamResult`). Кнопка «Спросить Бита» в шапке — без цены (цена видна в панели).
4. **Не хватает чипов** (`receipt.reason === "chips"`, ошибка `economy.noChips`) → `NoChipsNotice` вместо текста ошибки: «Нужно 10 чипов, у тебя 4» + «В магазин» (`/shop`) и «Безлимит» (`/plans?from=ai`). Потолок дня (`cap`) — старый текст `tutor.limit`. В `ExamResult` различать «нет чипов» и «лимит».
