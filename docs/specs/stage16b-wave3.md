## 0. Общие критерии готовности (для каждого урока каждого пакета)

1. **Ритм.** Не больше 3 информационных шагов подряд (story/theory/worked). Первое задание стоит не позже 4-го шага. После каждого разбора идёт задание на тот же приём. Ловушки — задание с `reveal`, а не разбор.
2. **Объём.** Карточка теории ≤ 90 слов (жёсткий предел 110), подшаг разбора ≤ 35 слов, сюжет ≤ 60 слов. Сюжет не пересказывает прошлые уроки. В уроке 14–18 шагов, 6–9 минут.
3. **Рисунки.** Сцена, которая не `table` и не `code`, есть минимум у половины карточек теории. В разборе не больше двух кадров-таблиц подряд. Сначала берём существующие сцены (`flow`, `venn`, `layers`, `pixels`, `lamps`, `coins`, `web`, `files`, `sizes`, `hardware`, `pc-inside`, `keyboard`, `circuit`), потом новые из §1.
4. **Задания.** В уроке 8–10 заданий, A/B/C ≈ 3/4/3 вместе с боссом. **Уровень C — другой тип рассуждения** (обратная задача, комбинация двух приёмов, ловушка, неизвестная цифра или основание), а не просто большее число. На урок допускается не больше одного «пересказа теории» (order шагов метода или match «термин — определение»).
5. **Чтение (решение #87).** В уроке на код (Python, SQL, таблицы, веб, БД) ≥ 2 задания `read` вида bug/fix/fill/purpose, а не только output. В остальных темах — «чтение готового» (URL, настройки сети, письмо, таблица, схема, G-code), ≥ 1 задание.
6. **Ввод и выбор (просьба владельца).** Слово или строку не вводим с клавиатуры: только плашки (`label`/`bank`) или choice. Числа — ввод. В уроке и в банке на уровнях B/C choice ≥ 40%. Неверные варианты — типичные ошибки (1000 вместо 1024, остатки сверху вниз, стоп включён, n вместо n−1, забыли ×8), у каждого `whyWrong`.
7. **Банк навыка.** ≥ 15 **разных** заданий на уровень: это запас для «теста по разделу», который заменяет «сдать экстерном». Фиксированные пулы по 8 заданий заменить генераторами, где ответ считает код.
8. **ЕНТ-файл.** Если урок разбит, файл делится по новым урокам. В каждом файле: ≥ 12 single, ≥ 4 multi, ≥ 4 match, в кодовых темах ≥ 2 context. Доля A ≤ 45%; A-определения («Что такое HTML?») заменить на чтение.
9. **Связки.** У урока есть финальный шаг, и он называет **настоящий** следующий урок по новому `course-map` (таблицу порядка даёт главная модель). Понятие подробно объясняется только в уроке-владельце (§4). В других уроках — одна строка-напоминание.
10. **Сохранение.** Id старых шагов не меняем, это нужно для SRS и прогресса. У новых шагов — префикс урока. Все строки ru + kk, `npm run review:kk`, в CHANGELOG пометка «вычитано моделью, носителем — нет». У каждого задания есть `hint`. `npm test` зелёный, `check-content` без предупреждений.

## 8. «Тест по теме» между группами (пакет П0 — код; до раундов контента)

Владелец: «между темами должны быть чисто тесты по пройденному». Сейчас это «Мини-тест» группы: 6 заданий ЕНТ (`MINITEST_COUNT`,
`lib/course-mix-meta.ts`, сборка `buildMiniTest` в `lib/course-mix.ts`), кнопка спрятана в листе «Практики» (`PracticeSheet`) и её почти не видно.

1. **Название и место.** «Мини-тест» → «Тест по теме» (ru) / «Тақырып бойынша тест» (kk). На дорожке — **отдельный узел** после «Практики»
   группы (значок `ClipboardCheck`, цвет `primary`; пройден на ≥ 80% — `success`, ниже — `warning` со счётом «7/10»). Узел открыт, когда пройдены
   все уроки группы; до этого — замок и подпись «Откроется после уроков темы». Кнопка в `PracticeSheet` остаётся (то же действие).
2. **Состав.** 10 заданий (`MINITEST_COUNT` = 10, `MINITEST_MIN` = 5): только задания ЕНТ по навыкам уроков группы (single, multi, match;
   context — если есть, не больше 1). Уровни B/C ≥ 60%, A ≤ 40%. Каждый урок группы — хотя бы одно задание (покрытие), дальше — равномерно.
   Без подсказок и ИИ, без маскота, звуков и XP (как пробный ЕНТ, RULES §1), разбор — после теста. 1 сердечко при «Начать» (волна 1, P1).
3. **Итог.** Баллы «как на ЕНТ» (`miniTestPoints`), список «Повторить: урок N — тема» по ошибкам (ссылка на урок и на тренировку навыка),
   ≥ 80% — «Тема закрыта», запись в `courseNodes` (уже есть `recordCourseNode(..., "minitest", доля)`). Чипы и бонусы — по волне 1Б (R1).
4. **Где мало заданий.** Если у группы < 5 заданий ЕНТ, узла нет (как сейчас). Пакеты раундов 1–5 поднимают ЕНТ-файлы (§0 п. 8), и узел
   появляется сам; главная модель после каждого раунда печатает список групп без теста (скрипт `scripts/out/minitest-coverage.ts`).
5. **Школа.** Тот же узел после «Упражнений» раздела школьной дорожки (волна 2, A.2) — общий компонент, группы класса.
6. **Тесты:** `tests/course-mix.test.ts` — 10 заданий, покрытие уроков группы, доля B/C, детерминированность по seed; `tests/course-nodes.test.ts`

7. **Файлы:** `src/lib/course-mix.ts`, `src/lib/course-mix-meta.ts`, `src/components/learn/PathView.tsx` (+ новый `TopicTestNode.tsx`),
