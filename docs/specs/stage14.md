### P2.1 Сборка сессий — `src/lib/course-mix.ts`
- Навыки урока — `LESSONS[id].skills`, только с банком (`hasBank`). Навыки группы/раздела — объединение без повторов.
- «Тронутый» навык: `stats[s]?.attempts > 0` **или** есть `LessonStat` у урока с этим навыком.
- **Практика** (`buildPractice(group, lessons, stats, seed)`, 12 заданий):
  - текущая = навыки группы (тронутые и нет);
  - недавние = навыки 3 групп **перед** этой в `COURSE_GROUPS` (через границы разделов), только тронутые, без навыков текущей;
  - давние = навыки всех групп раньше, только тронутые, без двух первых наборов;
  - доли: давние `round(0,2·n)`, недавние `round(0,3·n)`, текущая — остальное (12 → 6/4/2, 15 → 7/5/3); пустой набор отдаёт свою долю следующему (давние → недавние → текущая); пустая текущая → `[]`;
  - каждую долю собрать `buildFromBank(набор, stats, { count, seed: seed + k, cover: true для текущей })` — веса `(1,1 − освоение)²` и уровень по освоению уже внутри; освоение приходит затухшим (`DrillScreen`), поэтому давние и слабые выпадают чаще (#46);
  - итог — без повторов (по `id`), от лёгкого к сложному (A → C, порядок внутри уровня — как пришёл).
- **Повторение** (`buildRecap(unitId, …)`, 15 заданий): текущая = навыки всего раздела, недавние = 3 группы перед первой группой раздела, давние = всё раньше; те же правила.
- **Мини-тест** (`buildMiniTest(group, seed)`, 6 заданий): задания ЕНТ (`ENT_POOL`) с навыком из группы, без контекстных: 4 single + 1 multi + 1 match (не хватает multi/match — добрать single; всего меньше 6 — сколько есть; меньше 3 — `[]`); уровни по возможности 3 A + 2 B + 1 C; выбор детерминирован по `seed` (`seeded`); шаги — `entStepFromRef(entRef(id))` (match → `entmatch` целиком); **без `hint`** (это тест); порядок A → C.
- `miniTestPoints(steps, answers)` → `{ points, max }` как на ЕНТ: single/choice — 1 балл, multi и entmatch — 2 (балл = `score × max` по первой попытке).
- Тесты: доли 6/4/2 и 7/5/3; перераспределение у начала курса (первая группа — всё текущее); давние только тронутые; детерминизм по seed; мини-тест: состав, без hint, A → C, `[]` при нехватке; `miniTestPoints`.

   - нет шага `multi` с `ent` и 6 вариантами → так же одно «несколько верных»;
   - куда: сразу после последнего задания с `ent: true`; если таких нет — перед хвостом из шагов без ответа (финальная `theory`/`story`);
   - не дублировать (если id уже есть — не вставлять); исходный урок не мутировать.
3. Подключить в `LessonScreen`: режим «Учиться» — шаги `withEntBoss(lesson).steps`; «Проверить себя» — `buildCheck(withEntBoss(lesson), …)`. Сохранённые незаконченные прохождения со старым набором шагов сбросятся сами (подпись `sig`) — это ожидаемо.

## P4 — практикум: «Стоп», задача с кодом в уроке, контекстные задания с запуском (#85)

**Файлы:** `src/components/ide/python/*`, `src/lib/ide/python/runner.ts` (при необходимости), `src/components/lesson/steps/CodeStepView.tsx` (реализовать заглушку), `src/components/scenes/CodeScene*` (кнопка «Запустить» при `scene.run`), `src/lib/context-drill.ts` (реализовать заглушку) + `tests/context-drill.test.ts`, страница `src/app/(main)/code/context/page.tsx` (+ клиентский компонент в `src/components/ide/`), карточка-вход на `/code` (`components/ide/IdeHub.tsx`), `src/i18n/parts/ide-run.ts`; e2e `e2e/ide-run.spec.ts`.
**Не трогать:** `evaluate.ts`, `LessonPlayer.tsx`, `DrillScreen.tsx`, типы, задачи практикума (`lib/ide/*/tasks.ts` — их пишет контент-пакет C9).

1. **«Стоп»:** в рабочей области Python, пока идёт запуск, проверка или трассировка, кнопка «Запустить» становится «Стоп» (иконка `Square`) → `stopPython()`; статус «Программа остановлена» (нейтральный). Автостоп по таймауту остаётся. Для JavaScript — так же, если там свой воркер (иначе пропусти и отметь).
2. **`CodeStepView`** (`StepProps<CodeStep>`): задача по `step.task` из `lib/ide/python/tasks.ts`; сверху `step.prompt` (вводная урока), затем условие задачи (markdown); редактор — тот же, что в практикуме (`components/ide/CodeEditor.tsx` / `CmEditor.tsx`), с начальным кодом; кнопка «Проверить код» → `checkPython(task.check, code, runPython, PY_FORBID[task.id])`:
   - прошло → `onAnswer({type:"code", ok:true, tries, code}, {submit:true})`;
   - не прошло → показать тест (ввод / ожидалось / получилось), можно править и проверять снова (`tries + 1`); кнопка «Показать решение» → `onAnswer({type:"code", ok:false, tries, code}, {submit:true})`;
   - первая загрузка Python — «Загружаю Python…» с пояснением, что это один раз; не загрузился (нет сети) — сообщение и подсказка нажать «Пропустить» (кнопка плеера);
   - «Стоп» во время проверки;
   - после проверки (`locked`) — эталон `task.solution` только для чтения, если решение не найдено; подсказка задачи (`task.hint`) — по кнопке «Подсказка» внутри шага (бесплатно).
   - XP и `codeTasks` здесь не трогаем: ответ урока уходит в освоение через плеер.
3. **Сцена кода с запуском** (`scene.run`, только Python): под кодом кнопка «Запустить», поле «Ввод» (если программа читает `input()`, несколько строк), окно вывода, «Стоп». Без `run` — как раньше.
4. **`context-drill.ts`:** `contextItems()` — все `kind:"context"` из `ENT_POOL` в порядке курса (по порядку уроков в `UNITS`); `buildContextDrill(id)` — 5 шагов `entStepFromRef(entRef(id, n))`, n = 0..4, у сцены кода Python — `run: true`; неизвестный id — `[]`. Тесты.
5. **Страница `/code/context`:** заголовок «Контекстные задания», пояснение «Программа и 5 вопросов к ней — как на ЕНТ. Программу можно запустить.»; список карточек (навык, урок, уровень A/B/C, «5 вопросов») → `/drill?mode=context&item=<id>`; на `/code` — карточка-вход. Мобильная вёрстка, тёмная тема.
6. e2e: «Стоп» останавливает `while True: pass`; контекстное задание открывается, «Запустить» печатает вывод; шаг кода в уроке — нужен урок с `code` (появится после C9a) — проверь на тестовой странице или пропусти и отметь.

**Готово, когда:** долгую программу можно остановить; шаг `code` работает в уроке (проверка, повторная проверка, решение, пропуск); контекстные задания открываются из практикума и программу можно запустить; скриншоты 360 px; тесты зелёные.

## Контент-пакеты (C1–C9) — общие требования

- Образцы: соседние уроки той же темы; для микроуроков — компактная версия методики (RULES.md §4.1): `story` → `theory` со сценой → `worked` (2–3 подшага со сценами) → 1–2 задания → ловушка (`theory` или задание с `reveal`) → задания → задание в формате ЕНТ → короткий итог (`theory`). **9–12 шагов, 4–6 заданий (из них ≥ 1 с `ent: true`: `choice` на 4, `multi` на 6 или `entmatch` 2×4), `durationMin` 3–5, конспект 300–800 знаков**, `micro: true`, `skills` — навык родительского урока (у него уже есть банк), `unitId` и `entTopics` — как у родителя. Свой банк и файл ЕНТ **не нужны**.
- Задания ЕНТ — RULES.md §4.5 (single — ровно 4 варианта и `whyWrong`; multi — ровно 6, 2–3 верных; match — ровно 2 пункта × 4 описания; у всех `hint` без ответа и `explanation`); уровни ≈ 50/30/20; дистракторы — типичные ошибки; id `<урок>:<имя>` уникальны; `topic` — из `entTopics` урока.
- Казахский — RULES.md §4.9 (глоссарий НЦТ, `kkSuffix`, ҰБТ).
- 100% корректность: каждую программу — `python3`, SQL — `sqlite3`, формулы таблиц — моделированием на `python3`. Список проверок — в отчёте.
- После правок: `npx tsx scripts/check-content.ts <id>` по каждому уроку — 0 ошибок; `npx vitest run tests/content*.test.ts tests/lessons*.test.ts tests/scenes*.test.ts`.

### C1 — микроуроки «Ветвления»: `py-2a-if`, `py-2a-else`, `py-2a-elif` (навык `py.if`)
- `py-2a-if` «if: если условие верно» — сравнения `>`, `<`, `==`, `!=`, `>=`, `<=`; одна ветка; отступ 4 пробела; «если условие ложно — строка не выполнится».
- `py-2a-else` «if–else: два пути» — ровно одна из двух веток; чётность через `% 2`; ловушка: `else` без условия.
- `py-2a-elif` «elif: выбор из нескольких» — проверка сверху вниз до первого истинного; порядок условий важен (оценки 5/4/3); ловушка ЕНТ: «что выведет при x = …».
- `py-2-if` (родитель) — поменять только название на «Ветвления: собираем вместе» (kk по смыслу) и текст первого `story` (теперь это урок-сборка после трёх микроуроков: «ты уже знаешь if, else и elif — соберём всё вместе и разберём ловушки ЕНТ»). Шаги и id не менять.
- Файлы: `src/content/lessons/py-2a-*.ts`, `src/content/lessons/py-2-if.ts`.

### C2 — микроуроки «range»: `py-3a-range`, `py-3a-range2`, `py-3a-step` (навык `py.for`)
- `range(n)`: 0…n−1, «сколько раз выполнится»; `range(a, b)`: b не входит, пустой диапазон; `range(a, b, шаг)`: шаг, счёт вниз с отрицательным шагом, `len(range(…))`. Трассировка — сценой `code` с `vars`/`output`.
- Файлы: `src/content/lessons/py-3a-*.ts`.

### C3 — микроуроки «Срезы»: `py-4a-index`, `py-4a-slice`, `py-4a-step` (навык `py.strmethods`)
- Индексы с 0 и с конца (−1), `IndexError`; срез `[a:b]` (b не входит, пропуски `[:b]`, `[a:]`); срез с шагом `[::2]`, `[::-1]`, отрицательные границы. Ответы — `python3`.
- Файлы: `src/content/lessons/py-4a-*.ts`.

### C4 — микроуроки «Ссылки»: `data-2a-relative`, `data-2a-absolute`, `data-2a-mixed` (навык `sheets.refs`)
- Относительная ссылка при копировании (сдвиг строки/столбца); абсолютная `$A$1` (не едет); смешанная `$A1` / `A$1` (что закреплено). Сцена `table` с адресами; задачи «какая формула окажется в ячейке …», «какое значение».
