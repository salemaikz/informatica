## Общие правила для всех пакетов

- Работаешь **в своей рабочей копии** (git worktree). Перед `tsc`: `cp -al <основной репозиторий>/node_modules ./node_modules`, `npx next typegen`.
  Проверки: `npx tsc --noEmit -p .`, `npx eslint <свои файлы>`, `npx vitest run <свои тесты>` (весь `npm test` можно, если быстро).
  `npm run build`, dev-сервер и e2e **не запускать** — их запускает главная модель.
- Свои файлы — только из списка пакета. **Общие файлы** (`src/lib/types.ts`, `src/i18n/dict.ts`, `src/content/course*.ts`,
  `src/content/skills.ts`, `src/lib/bank/index.ts`, `*generated*`, `tests/validate.ts`, `tests/content.test.ts`) не трогать;
  если без правки нельзя — опиши нужную правку в отчёте. `src/lib/store.ts` — можно только в своём участке (перечислен в пакете).
- Строки интерфейса — только в своей части словаря `src/i18n/parts/<часть>.ts` (заготовка уже подключена в `dict.ts`),
  ru и kk; в русском — без глаголов с родом («у тебя получилось»). Казахский — литературный, термины по глоссарию НЦТ (`docs/ENT.md` §4).
- Иконки — `lucide-react`, без эмодзи. Цвета — токены по смыслу (gold — XP/чипы/награды, streak — серия, heart — только сердечки,
  ai — всё, что делает ИИ, primary — действия). Анимации — пресеты `components/motion/presets.ts`, `useReduceMotion`.
- `setState` синхронно в эффекте нельзя; `Date.now()` в рендере нельзя. Новое поле стора — дефолт + санитайзер в `mergeState`.
- Клиентские модули не импортируют `@/content/course`, `@/lib/drill`, `@/lib/bank`, `@/content/ent` (сторож `tests/bundle-guard.test.ts`);
  лёгкое — `@/content/catalog`, `@/content/course-map`, `@/lib/drill-meta`.
- Тесты на чистую логику — в `tests/`. Коммить в свою ветку небольшими коммитами с понятными сообщениями (по-русски).
- **Отчёт** (финальный ответ): что сделано, список файлов, что проверено, что не получилось/вопросы, какие правки нужны в общих файлах.

Заготовки, уже сделанные главной моделью: `src/lib/tips.ts` + поле стора `tips` и действия `noteTip(id)`, `resetTips()`;
`ClozeBlank.label?: L` и `ClozeStep.bank?: L[]` (+ проверки в `tests/validate.ts`); части словаря `tour`, `unit-test`, `xp-sign`,

## P4. Дружеские уведомления (#101)

Тон — **дружески-дерзкий** (выбор владельца), на «ты», коротко, **только правда**: прогресс не пропадает, поэтому «весь прогресс потеряешь» нельзя.
Правда, которой можно пугать: серия сгорит (если заморозок не хватит), навыки «тают» без практики (`decaySkills`), копятся уроки «пора повторить»,
не будет бонуса за цель дня. Без эмодзи, без глаголов с родом в русском («пропал/пропала» — нельзя), имя ученика — можно в части текстов.

1. **Пул текстов** по ситуациям, у каждой — 3–5 вариантов (всего 18–25 на язык):
   серия под угрозой (без заморозки) · серия под угрозой (заморозка есть) · серии нет, начать новую · вернуться после паузы 2–6 дней ·
   после паузы 7+ дней · пора повторить N уроков · навыки начинают забываться · следующий урок «название» · вечер, цель дня не добита.
   Примеры тона (не копировать слово в слово): «Серия 5 дней сгорит в полночь. 5 минут — и она живёт», «Бит заскучал. Один урок — и снова в деле»,
   «3 урока ждут повторения, пока всё не выветрилось», «Неделя без информатики? ЕНТ сам себя не сдаст. Начнём с короткого урока».
2. **Выбор**: по ситуации с приоритетом (серия под угрозой > повторение > возврат > следующий урок > мотивация), вариант — по дню
   (детерминированно, чтобы не повторяться два дня подряд). Раз в день, как сейчас.
3. Тексты — данными (а не ветвлениями в коде), одним модулем `src/lib/reminder-texts.ts`; `public/sw.js` (без сборки) получает их
   через зеркало в IndexedDB (`components/goals/push.ts`, `ReminderMirror`) — расширь зеркало: имя, сколько повторить, название
   следующего урока (ru/kk), цель дня и XP сегодня, дни без занятий. Старое зеркало без новых полей — работает с простыми текстами.
   Тест сверки `sw.js` ↔ `lib/reminders.ts` (`tests/reminders.test.ts`) поддержать.
4. Баннер на главной (`StreakReminder`) и тестовое уведомление в профиле — из того же пула.
5. Тесты: выбор по ситуации и детерминированность, нет глаголов с родом (существующий тест распространить), нет эмодзи,
   казахские окончания после чисел — только через `kkSuffix` или фразы без окончаний.

**Сценарий** (состояние — `useApp.tips` из `src/lib/tips.ts`, `noteTip(id)`; всё — один раз):

## P7. Контент: выбор вместо ввода слов (#103)

Владелец: «не ввод текста, а выбор из вариантов для таких вопросов, или мешать ввод и выбор». В уроках 136 ответов с `mode: "text"` в 54 файлах.

Правила:
- **Пропуск со словом** (`cloze`, `mode: "text"`, ответ — слово/словосочетание естественного языка, у которого есть формы: «ввода/вывода»,
  «процессор», «енгізу») → добавить `label: { ru, kk }` (как показать на плашке; нормализованный текст обязан входить в `blank`; если формы нет —
  добавь её в `blank`) **ко всем текстовым пропускам шага** и `bank: L[]` — 2–3 правдоподобных отвлекателя на шаг (не верные ни для одного пропуска).
- **Поле ввода со словом** (`type: "input"`, `mode: "text"`, ответ — слово/фраза) → заменить на `type: "choice"` (вопрос тот же, 4 варианта:
  верный + 3 правдоподобных отвлекателя, `correct`, `whyWrong` для каждого неверного, `explanation` — как было, `id` шага — **тот же**,
  `skill`/`level`/`hint` — как были).
- **Код, теги, ключевые слова, функции** (`td`, `WHERE`, `len`, `СУММ`, `print`) — набор этих токенов тоже навык: в уроке оставь вводом
  **не больше половины** таких пропусков/полей, остальные — выбор (так получится «мешать ввод и выбор»). Числа и двоичные — ввод как есть.
- Проверка: `npx tsx scripts/check-content.ts <id>` по каждому изменённому уроку и `npx vitest run tests/content.test.ts` — зелёные.

Делится на 3 исполнителей по списку файлов (`grep -c 'mode: "text"'`). Файлы — только уроки из своего списка (`src/content/lessons/<id>.ts`).
Банки заданий (`src/lib/bank/*`) в этой волне не трогать.
