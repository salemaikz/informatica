# ТЗ: практикум кода 2.0 — 40 → 100+ задач (v0.8)

> Часть курса 2.0 (решение #38): практикум должен давать практику на все 12+ недель. Сейчас 40 задач (Python 10, SQL 8, HTML/CSS 8, JS 6, Excel 8). Формат задач, проверок и правила — `docs/specs/ide.md`, типы — `src/lib/ide/types.ts`.

## Сколько и каких задач добавить

Задачи идут от A к C, у каждой — `skill` из **новых навыков курса 2.0** (`src/content/skills.ts`, уроки — `docs/specs/course-v2.md`), `hint` (без ответа), эталон `solution` и проверка. Стиль условий — как сейчас в файле (коротко, как в ЕНТ, формальное «Выведите»; казахский — литературный, «-ңыз/-ңіз»). Слова в выводе Python/JS — латиницей.

| Язык | Было | Добавить | Темы (навыки) |

## Интерфейс
- Список задач языка (`src/components/ide/TaskList.tsx`): при > 12 задачах — **группы по навыку** (заголовок навыка из `skillById`, задачи внутри — от A к C), группа с нерешёнными сверху раскрыта; счётчик «решено 3 из 8» у группы.

## Проверки
- Каждый эталон проходит свою проверку (тесты `tests/ide-<lang>.test.ts` уже прогоняют все эталоны — убедись, что новые задачи туда попадают), стартовый код — **не** проходит.
- `npx vitest run tests/ide-*.test.ts`, `npx eslint <файлы>`, `npx tsc --noEmit -p . 2>&1 | grep -v "src/content/\|src/lib/bank/"`. Не запускать build, dev, git.
