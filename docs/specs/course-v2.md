# ТЗ: курс 2.0 — в 2,3 раза больше уроков (v0.8)

> Отзыв пользователя (2026-10-03): «нужно больше контента, не может быть, чтобы за такое маленькое количество коротких уроков мы могли объяснить всё, что попадётся на ЕНТ… за месяц человек всё пройдёт, будет маленький LTV — нужно минимум 3 месяца и более». Решение #38.

## 1. Цель и расчёт

- Было: 50 уроков ≈ 6 часов чистого времени — проходится за 2–4 недели.
- Стало: **113 уроков** (+63). Каждая тема ЕНТ разобрана на отдельные навыки, у каждого — урок, банк тренировки и задания ЕНТ. С тренировками, повторением (1-3-7-14-30-60), практикумом кода и пробными ЕНТ это **12+ недель** по 20–30 минут в день.
- Принцип: **один урок — один навык**, без «всё в одном». Большие старые уроки (например, `py-7-algos` «Сортировка, поиск, файлы и графы») остаются обзором, а новые уроки разбирают каждую часть глубоко, с задачами уровня C.

## 2. Как писать (для авторов)

Формат, правила и самопроверка — **`docs/specs/content.md`** (главное), `docs/CONTENT_GUIDE.md`, `docs/ENT.md` (форматы ЕНТ, термины kk — раздел 4). Образцы — уроки той же темы, которые уже есть (их надо прочитать, чтобы **не повторять** и **опираться** на них: «в уроке «Циклы» ты уже видел…»).

Каждый урок — **три файла** (создаёшь сам, ничего не регистрируешь):
1. `src/content/lessons/<id>.ts` — `export const lesson: Lesson` (`id`, `unitId`, `skills: [<навык>]`, `entTopics`, `durationMin` 6–9, **14–18 шагов**, конспект 500–1200 знаков на каждом языке).
2. `src/lib/bank/<id>.ts` — `export const BANKS: SkillBank[]` через `poolBank` (`src/lib/bank/pool.ts`): **≥ 18 вопросов (≥ 6 на уровень A/B/C)**, ≥ 10 утверждений «верно/неверно», ≥ 8 пар, `short` — где есть однозначный короткий ответ (≥ 8). У каждого вопроса — `hint` (не выдаёт ответ) и `explanation`; у `choice`/`multi` — `whyWrong`. Для расчётных навыков можно генератор с параметрами (как в `src/lib/bank/ns.ts`), если ответы считает код.
3. `src/content/ent/<id>.ts` — `export const ITEMS: EntItem[]`: **≥ 12 single, ≥ 4 multi, ≥ 4 match**, уровни A/B/C (≈ 50/30/20), id `<id>:<имя>`. **У каждого задания — `hint`** (ru/kk, 1–2 предложения, первый шаг, без ответа) — подсказки одни на всех и бесплатные, ИИ на них не тратится. Для Python-уроков с пометкой «контекст» — ещё **≥ 2 `context`** (программа + 5 вопросов, у каждого вопроса `hint`).

Требования к качеству (проверяет ревьюер):
- **Новичок поймёт**: каждый термин — после примера из жизни; карточка «Где это встречается»; 2–4 коротких абзаца на карточку; минимум 5 шагов со сценой (`code`, `table`, `circuit`, `flow`, `cards`, `web`, `pixels`, `hardware`, `layers`, `sizes`, `files`…).
- **Глубина ЕНТ**: разборы `worked` A → B → C, ловушка ЕНТ, `cloze`, 6–8 заданий от A к C, ≥ 2 задания `ent: true`, уровень C — настоящая задача ЕНТ (несколько шагов, обратная задача, объединение тем).
- **Правильность**: каждый ответ пересчитан (`python3` для кода и расчётов; программы на Python — запусти и сверь вывод); в `multi` ровно верный набор; в `match` — взаимно однозначно.
- **Казахский**: литературный, термины глоссария НЦТ и курса (айнымалы, цикл, шарт, функция, тізім, жол, деректер қоры, сұраныс, кесте, ұяшық, сілтеме, жинақтауыш, қатты диск, жедел жад, қалта, кеңейтілім, программа, түйме, тіркесім), «ҰБТ» (не «ЕНТ»), без падежа сразу после `{плейсхолдера}`, пол ученика не угадывать.
- **Не трогать** общие файлы: `course.ts`, `skills.ts`, `types.ts`, `generated.ts`, `i18n/*`, `tests/*`, сцены, чужие уроки. Не запускать `scripts/register-content.mjs`. Урок уже стоит на карте (статус «скоро» — станет «готов» после регистрации главной моделью).

Самопроверка: `npx tsx scripts/check-content.ts <id>` — 0 ошибок, предупреждений минимум (в том числе «нет hint»); `npx eslint <3 файла>`; `npx tsc --noEmit -p . 2>&1 | grep "<id>"` — пусто (ошибки в чужих файлах игнорируй: другие авторы пишут параллельно).

## 4. Порядок работы (главная модель)

1. Навыки — в `src/content/skills.ts`, уроки — на карте в `src/content/course.ts` (статус «скоро» до регистрации). ✅
2. Параллельные потоки авторов (`sonnet`) → строгий ревьюер (методист + проверка фактов + казахский редактор, `opus`) → исправления ревьюером.
3. После каждого потока: `node scripts/register-content.mjs`, `npm run typecheck && npm test`, выборочные скриншоты.
4. Казахский — вычитан моделью; в CHANGELOG — «вычитано моделью, носителем — нет».
