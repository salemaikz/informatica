## 4. P2a — Всплывающий Бит-проводник (пункт A + «всплывал и рассказывал, со звуком»)

### 4.1 Что меняется для ученика
Сейчас: карточка с Битом **вверху страницы** (`PageTip`), затемнение с пузырём (`Spotlight`), отдельная подсказка в уроке
(`LessonFirstTip`) и карточка «Что всё это значит» на итогах (`AfterFirstLesson`) — всё «прочитай и нажми Дальше».
Нужно: **Бит выпрыгивает снизу** (из угла, где живёт плавающая кнопка Бита из P2b), **говорит** (текст печатается, с «голоском»),
**показывает** на элемент (пульсирующая рамка + палец-указатель), **просит действие** («нажми на сердечко») и **ждёт нажатия именно туда** —
нажатие проходит в сам элемент. Одно действие на экран, сцены короткие (2–4 реплики).

### 4.2 Логика — `src/lib/guide.ts` (чистая, тесты `tests/guide.test.ts`)
```ts
export type GuideAction = "next" | "tap";
export interface GuideStep {
  id: string;
  /** Метки `data-tour`; рамка — их объединение. Нет — Бит просто говорит (без затемнения). */
  targets?: readonly string[];
  text: DictKey;                  // ключ `guide.*`; для школьного трека можно `textSchool`
  textSchool?: DictKey;
  mood?: Mood;
  /** next — кнопка «Дальше»/«Понятно»; tap — ждём нажатия на цель (кнопки «Дальше» нет). */
  action: GuideAction;
  /** Ждать появления цели (мс). Не появилась — шаг пропускается. По умолчанию 1500. */
  waitMs?: number;
  /** Только для ЕНТ-трека (`entVisible`). */
  ent?: boolean;
}
export interface GuideScene { id: TipId; steps: readonly GuideStep[] }
export const GUIDE_SCENES: Record<SceneId, GuideScene>;
export function sceneFor(tips, ctx: { pathname; onboarded; completedLessons; inLesson; onResults }): SceneId | null;
export function placeBit(target: Rect | null, vp: { vw; vh; bottomInset }): { corner: "br" | "bl"; bubble: "above" | "side" };
```
- Состояние «показано» — как сейчас, `useApp.tips` / `noteTip` (`lib/tips.ts`); новые id — в `TIP_IDS` (`page-shop`, `page-profile`, …).
  Сцена отмечается показанной, когда доиграна, пропущена или ученик ушёл со страницы посреди неё.
- «Пропустить» — закрывает **весь** проводник (все подсказки, как сейчас); Escape — то же. «Показать подсказки снова» в профиле работает.
- `placeBit`: Бит в правом нижнем углу (над нижней панелью); если цель в правой нижней четверти или Бит её закрыл бы — в левом нижнем;
  пузырь — над Битом, если цель в нижней половине — сбоку от Бита. Тесты на геометрию (узкий 360 px и широкий экран).

### 4.3 Вид — `src/components/guide/*` (заменяет `components/tour/*` целиком; `TourAgent` в `Providers` заменить на `GuideHost`)
- `GuideHost` — решает, какую сцену играть (`sceneFor`), пауза 600 мс после прихода на страницу, ведёт шаги, ставит `useGuideUi.active`.
- `BitPopup` — Бит размером 72 px **выезжает снизу** из угла с пружиной (из-за края экрана, лёгкий «прыжок» и наклон), рядом — пузырь.
  Текст **печатается** (~40 знаков/с; касание пузыря — допечатать сразу). Кнопки: «Дальше» / «Понятно» (для `next`), маленькая «Пропустить».
  Для `tap` — вместо «Дальше» строка-подсказка мелко: «Нажми, куда показываю». Между шагами Бит не исчезает — меняется реплика
  и настроение (`Mood`); в конце сцены — уезжает вниз. Цвета: пузырь как сейчас (`surface`, `border`), кнопки `primary`.
- `GuidePointer` — у цели: **пульсирующая рамка** (повторяет форму элемента, `primary`) и **палец-указатель** (`lucide` `Pointer`
  или рисованный), который «тычет» в цель со стороны Бита. Цель на экране не видна — прокрутить к ней (`scrollIntoView` с отступом под шапку).
- **Затемнение** — только у шагов с целью: лёгкое (≈35%), вырез вокруг цели собран из 4 прямоугольников, поэтому **цель остаётся
  нажимаемой**; нажатие на затемнение — Бит коротко «качает головой» (ничего не происходит). Шаги без цели — без затемнения, страница работает.
- **Звук** (`src/lib/sound.ts`): `bitPop` — появление (мягкий «буп» вверх), `bitTalk` — слог «голоска» (40–70 мс, высота 480–780 Гц
  случайно, треугольник + low-pass, лёгкое вибрато); при печати — слог на каждые 2–3 буквы, не чаще раза в 70 мс, на пробелах пауза.
  Подчиняется настройке «Звук» (как все звуки). «Меньше анимаций»: текст сразу целиком, без прыжков (выезд — простое проявление),
  звук — один `bitPop`.
- Доступность: шаг с затемнением — `role="dialog"` `aria-modal`, фокус на «Дальше» (для `tap` — на цели); без затемнения — `role="status"`
  `aria-live="polite"`. Полный текст реплики — сразу в `aria-label`/скрытом тексте (печать — только визуально).
- Не показывать: онбординг, пробный ЕНТ и тесты в формате ЕНТ, игры (кроме сцен, явно привязанных к ним — таких нет).

### 4.4 Сцены (тексты ru — эти; kk — перевести; ключи `guide.*`)

и конспект; плата ½ сердечка списывается **молча** (через 15 с или после прокрутки) и не берётся, если урок пройден, тариф «Безлимит»
(в том числе пробный) или уже платили за сутки — поэтому владелец не видит, что теория платная.

### 10.1 Плата — ½ сердечка при открытии темы (уточнено владельцем 2026-10-06)
- Открыл тему (страницу урока теории) — списано ½ сердечка, как вход в урок. Без бесплатной первой карточки, без кнопки-ворот
  и без отдельных пояснений про плату на странице («при нажатии просто 0,5 сердца, и всё»). Цена видна только обычным значком
  сердечка на карточке темы в списке (как у уроков).
- Пройденный урок — тоже платно. Не списывается повторно при возврате к той же теме в течение суток и на «Безлимите».
- Нет сердечек — обычное окно «Сердечки закончились» (`OutOfHearts`), текст темы не показывается.

### 10.2 Не «всё сразу», а по шагам и с понятной последовательностью
- `/theory` (`TheoryHome`): поиск сверху; блок «Продолжить чтение» (последний открытый конспект — поле в сторе `theoryLast`);
  ниже **разделы списком** (номер раздела, название, «прочитано N из M», полоска), свёрнутые; раскрыть раздел — **уроки по порядку**
  с номерами «1. …», «2. …» и значками: пройден / прочитан / не начат / скоро. Не больше одного раскрытого раздела за раз (или раскрыт
  раздел текущего урока). Ссылка `/theory?unit=u3` раскрывает и прокручивает к разделу (старое `#u3` при полной загрузке тоже работает; в приложении — только параметр: при переходе внутри приложения `window.location.hash` в первом рендере ещё старый).
- `/theory/<id>` (`TheoryReader`):
  - вверху — «хлебные крошки»: «Раздел 2 · Логика» → «Урок 3 из 8»; под ними — **лента уроков раздела** (кружки с номерами, текущий
    выделен, пройденные — `success`), нажатие — к другому уроку раздела;
  - карточки урока — **по одной** (как шаги урока): «Карточка 2 из 5», точки-прогресс, кнопки «Назад» / «Дальше», свайп влево/вправо;
    последняя — «Конспект» (итог урока) и кнопки «Пройти урок», «Проверить себя», «Сохранить в конспекты», «Следующий урок теории»;
  - переключатель «По карточкам / Всё сразу» (по умолчанию — по карточкам; выбор запоминать) — для повторения можно и списком;
  - ссылки из поиска (`/theory/<урок>?card=<id шага>`, `?card=conspect`) открывают нужную карточку (страница читает параметр на сервере и передаёт в `TheoryReader` проп `initialCard`; старые `#<id шага>` при полной загрузке тоже работают); пока тема не открыта (оплата или нет сердечек), карточек нет и в «Продолжить чтение» ничего не пишется. После первого листания `?card=` из адреса убирается; при «Назад» к такой записи Next поднимает прежние пропсы, поэтому читалка сверяет параметр с адресом роутера (`useSearchParams`, `liveCardParam`) и, если в адресе его уже нет, открывает место из `theoryLast`.
- Чистая логика (порядок уроков раздела, номер урока в разделе, «следующий для чтения») — `lib/theory.ts`, тесты.

### 10.3 «Спросить Бита по этой теме»
- Заметная кнопка (фиолетовая, `ai`) на странице урока теории: «Спросить Бита об этой теме». Открывает **чат по теме урока**: новый чат
  (или уже созданный для этого урока — не плодить одинаковые) с названием урока, темой ЕНТ урока (`topic`) и контекстом урока
  (название + конспект, обрезанный по бюджету `server/context.ts`), чтобы ответы держались этой темы. Первое сообщение — статическое,
  без ИИ: «Спрашивай всё про «{урок}». Например: …» и 3 подсказки-кнопки. Цены ИИ — как у чата.
- Если для контекста урока в чате нужен новый режим/поле в промпте — минимально, через `server/prompts.ts` (изменение промпта —
  отдельной строкой в отчёте для CHANGELOG; поднять `PROMPT_VERSION`). Кнопки «Спросить Бита» у отдельных карточек — оставить.
- Пока чат открывается страницей `/tutor/<id>`; после слияния с P2b главная модель переключит на панель плавающего Бита.

## 11. P8 — «Нужна помощь?» по времени чтения (пункт C, волна 2)

> Владелец: «через время нейронка спрашивает: вам помочь? По количеству текста нужно сделать скрипт на среднее время, через которое
> выходить будет плашка помощи нейронки (сколько нужно времени на слайд)».

- **Оценка времени — чистая функция** `expectedStepMs(step, lang, level?)` в `src/lib/help-timer.ts` (тесты): время чтения всего текста шага
  (условие, варианты, подписи сцены, код) при скорости ≈ 3 слова/с (ru) и ≈ 2,5 слова/с (kk), формулы и код — медленнее; плюс время
  на действие по виду шага (выбор ≈ 6 с, ввод ≈ 12 с, порядок/пары ≈ 15 с, шаг-рассказ 0) и множитель уровня (A ×1, B ×1,3, C ×1,6).
  Порог плашки `helpAfterMs = clamp(expected × 1,75, 20 с, 180 с)`.
- **Скрипт** `npm run step-times` (`scripts/step-times.ts`): по всем урокам и банку — среднее/медиана/максимум по видам шагов и уровням,
  10 самых «долгих» шагов; пишет отчёт `docs/content/step-times.md`. Это ответ владельцу «сколько нужно времени на слайд».
- **Где:** урок (режим «Учиться» и «Проверить себя»), тренировка. **Не** в пробном ЕНТ, мини-тесте, тесте по теме и по разделу
  (там ИИ выключен, решения #17, #20) и не в играх. Считается только активное время (вкладка видна), шаг сменился — счёт заново;
  пока открыта шторка/окно или идёт сцена проводника — пауза. Один раз на шаг, не больше 3 раз за урок/тренировку; ученик уже
  взял подсказку на этом шаге — не показывать.
- **Вид:** маленький Бит (как у проводника — `BitPopup`/`placeBit` или облегчённый вариант на тех же стилях и звуке `bitPop`) выглядывает
  снизу у кнопки «Проверить», без затемнения, не модально. Вопрос: «Долго думаешь? Могу дать подсказку.» — кнопки «Подсказка» (цена ИИ —
  существующий `AiCost`; бесплатные подсказки автора — как сейчас) и «Нет, спасибо». На шаге-рассказе (без вопроса): «Объяснить проще?» →
  «Спроси Бита» с вопросом «объясни проще». Любой ответ ученика или «Нет, спасибо» — Бит уезжает. Цвет кнопки помощи — `ai`.
- Кнопки ведут в **уже существующие** пути помощи плеера (кнопка «Спроси Бита» `lesson-ask`, подсказка) — новых вызовов ИИ нет.
- Строки — `src/i18n/parts/help16c.ts` (`help16c.*`). Тесты: оценка времени, порог, «один раз на шаг / не больше 3».
