**Файлы:** `src/app/(main)/learn/page.tsx`, `src/components/learn/*` (новые), `src/i18n/parts/learn.ts` (префикс `learn2.`; старые ключи `learn.*` в `dict.ts` можно использовать).

Цель — красивая, живая и удобная карта, как в лучших учебных приложениях, но без перегруза.

Структура главной сверху вниз:

   - **Раздел** = «местность»: карточка-шапка с иллюстрацией по `unit.theme` (лёгкий SVG-декор в цвете раздела, свой у каждой темы: `numbers` — парящие 0/1 и острова; `logic` — вентили и переключатели; `code` — скобки и терминал; `data` — таблицы и цилиндры БД; `hardware` — чип и дорожки платы; `network` — глобус и узлы; `office` — сетка таблицы; `future` — ракета и звёзды; `summit` — гора с флагом), номер и название раздела, «N из M уроков», кольцо освоения (среднее `mastery` навыков раздела), кнопки «Теория раздела» (`/theory#<unitId>`) и «Сдать экстерном» (`/drill?mode=extern&unit=<id>` — только если в разделе есть готовые непройденные уроки).
   - **Дорога**: извилистая SVG-кривая через узлы уроков (узлы змейкой влево-вправо по плавной синусоиде, а не столбиком), пройденная часть дороги — цветом раздела, остальная — пунктиром `border`. Узел урока — круглая «кнопка» 64–72 px с объёмным низом (как сейчас), состояния: **пройден** (золотой, звезда; маленький бейдж «×N» при повторах), **рекомендуемый** (цвет раздела, пульсирующее кольцо, рядом стоит маскот `Mascot` 40 px с облачком «Начать»), **доступен** (цвет раздела, иконка Play), **пора повторить** (как пройден + маленький оранжевый значок часов `streak`), **скоро** (серый, замок). Подпись урока — рядом с узлом (не только под ним), 2 строки максимум. Между разделами — небольшой «мостик».
   - **Все готовые уроки открыты** (свободный режим): можно начать любой урок любого раздела. Рекомендуемый — первый непройденный готовый урок по порядку (но ученик не обязан идти по порядку).
   - Анимации: узлы появляются каскадом при прокрутке (`Reveal`/motion, уважать «меньше анимаций»).
7. **Вид «Карта ЕНТ»**: 13 плиток тем ЕНТ (`ENT_TOPICS`) в сетке 2 колонки (на ≥ 640 px — 3), **размер плитки по весу** (`examCount` ≥ 4 — на всю ширину или двойная высота), **цвет — по освоению** темы (семантика CLAUDE.md: нет данных — серый `border`; слабо < 0.6 — `danger`; в процессе — `warning`; освоено ≥ 0.8 — `success`), внутри: название, «≈N заданий на ЕНТ», % освоения, число уроков. Сверху легенда цветов. Нажатие — шторка темы: уроки темы (по `lesson.entTopics`/навыкам), «Тест по теме» (`/exam/run?kind=topic&topics=<id>`), «Тренировать» (`/drill?mode=skill&skill=<первый навык>` или smart по навыкам темы — используй `/drill?mode=topic&topic=<id>`, этот режим добавит W2-2).
8. **Шторка урока (выбор режима)** — `components/learn/LessonSheet.tsx`, экспортируй её — её используют и другие экраны: заголовок, раздел, описание, длительность, число шагов, статус («Пройден ×2 · лучший 90% · повторить через 3 дня» / «Пора повторить»), **XP**: «первый раз — полный XP» / «повтор — ×0,5» / «повторение по плану — ×0,75» (`lessonXpFactor`), и **режимы** крупными кнопками-карточками:

Производительность: 42 урока, SVG — один на раздел; без тяжёлых картинок. Доступность: узлы — `button` с `aria-label` «Урок N: название, пройден». Проверь на 360 px и в тёмной теме.

## W2-2. Режимы урока, повторение, экстерн, урок игрой (`modes`)

**Файлы:** `src/app/lesson/[id]/LessonScreen.tsx`, `src/app/lesson/[id]/page.tsx`, `src/components/lesson/LessonPlayer.tsx` (кроме блоков `taskCtx`/панели обратной связи — их уже менял W1-5, не ломай), `src/components/lesson/Results.tsx`, `src/app/drill/DrillScreen.tsx`, `src/app/drill/page.tsx`, `src/lib/generators.ts` (только `buildDrill`, если нужно), `src/lib/drill.ts` (новый, чистая логика сборки сессий), `tests/drill.test.ts`, `src/components/games/GameShell.tsx`, `src/app/game/[id]/page.tsx`, `src/app/(main)/practice/page.tsx`, `src/i18n/parts/lesson-modes.ts` (префикс `modes.`).

1. **`/lesson/<id>?mode=check`** — «Проверить себя»: только задания урока (без теории/разборов/ситуаций), порядок A → B → C; если заданий меньше 6 — добрать из банка навыков урока (`draw("question", …)`). Сверху пометка «Проверить себя». Итог передаётся `finishSession({ …, via: "check" })`. `mode=learn` (по умолчанию) — как сейчас. Неизвестный mode — learn.
2. **XP за повтор**: в начале урока возьми множитель `lessonXpFactorNow(lessonId)` (`store.ts`) и умножай XP за ответы (`scaleXp`). Покажи в шапке урока маленькую пометку «Повтор: ×0,5 XP» (янтарный `warning`, не красный), если множитель < 1. В итогах (`Results`) — строка «Повтор урока: XP ×0,5» / «Повторение по плану: XP ×0,75» и «Следующее повторение через N дней».
3. **Итоги урока** (`Results`): блок «Что дальше» — кнопки «Следующий урок» (следующий готовый урок раздела или курса), «Повторить слабое» (`/drill?mode=smart`), «В конспект» (сохранить конспект урока — `useSaveToNotes.getState().open({ source: "lesson", lessonId, title, text: conspect })`).
4. **Тренировка** (`/drill`): новые режимы в `lib/drill.ts` (чистые функции, тесты):
   - `review` — «Повторение / разминка»: 8 заданий из навыков уроков, которые пора повторить (`dueLessons`), плюс слабые навыки; если нечего повторять — smart. По окончании (после `finishSession` с `kind: "drill"`) — `markReviewed(lessonIds, accuracy)` для уроков, чьи навыки были в разминке (точность считай по заданиям навыков этих уроков): стор сдвинет расписание повторения.
   - `extern` (`&unit=u2`) — «Сдать экстерном»: по 2 задания уровня B–C на каждый навык готовых уроков раздела (до 12), без подсказок ИИ? (подсказки и ИИ доступны — это обучение), в конце: ≥ 80% — `completeLessons(<готовые непройденные уроки раздела>, "extern", accuracy)` и экран «Раздел засчитан»; меньше — «Пока не получилось, начни с урока …».
   - `topic` (`&topic=t05`) — 8 заданий по навыкам темы ЕНТ (`SKILLS[].ent`).
   - `smart`/`skill` — **все навыки с банком доступны без замков** (свободный режим): smart — по пройденным урокам, а если их нет — по навыкам первого раздела; `skill` — любой навык.
5. **Урок игрой**: `/game/<id>?lesson=<lessonId>` или `?skills=a,b`: `GameShell` читает параметры (страница передаёт пропсами), передаёт `skills` в игру (`GameProps.skills`), показывает в шапке «Урок: <название>». Если игра в контексте урока закончена с точностью ≥ 70% (`correct/total`) — `completeLessons([lessonId], "game", accuracy)` и на экране итогов «Урок засчитан игрой». Игры без нужной формы для навыков — недоступны (кнопка «Играть» неактивна, пояснение).
6. **Страница «Тренировка»** (`practice`): карточка «Пробный ЕНТ» вместо «скоро» → `/exam`; список навыков — **без замков**, сгруппирован по разделам курса (свёрнутые группы, раскрывается раздел), у навыков без банка — «скоро»; игры — открыты, если хотя бы у одного навыка из `GameMeta.skills` (или для универсальных — у любых навыков пройденных уроков) есть нужная форма; для универсальных игр — подпись «к любой теме».

   - «Завершить» — подтверждение («осталось без ответа: 3»), затем `scoreExam`, `recordExam(summary, skillScores)` и переход на результат.
