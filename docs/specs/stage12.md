### P1.2 Приём событий (`/api/events`)
- Белый список и проверка — чистый модуль `lib/analytics-schema.ts` (общий для клиента и сервера): `parseEvents(body: unknown): AnalyticsEvent[]` — только события из `lib/analytics.ts` с полями нужного типа; строки-идентификаторы (`lesson`, `step`, `game`, `mode`, `item`) — `^[\w.:-]{1,80}$`; числа — целые в разумных пределах (`acc`/`pct` 0–100, `sec` 0–7200, `step`/`of` 0–200); лишние поля отбрасываются, неизвестные события — тоже; в пачке не больше 30 событий.
- Маршрут: `POST`, защита как у `/api/issue`: `sameOrigin` → лимит по IP **до чтения тела** (ключ — хеш IP, не сырой IP: `ipKey`/хеш, как в страже ИИ; вынести общий помощник, не меняя `ai-guard.ts` — скопировать хеширование в `server/ip-hash.ts`) → чтение тела потоком ≤ 4000 байт (вынести `readBodyText` из `app/api/issue/route.ts` в `server/body.ts`, issue-маршрут перевести на него) → `parseEvents` → суточный потолок событий на сайт (50 000) → агрегация → `204`.
- Выключено, если не `NEXT_PUBLIC_ANALYTICS === "1"` (ответ `204`, ничего не пишется).
- **Хранение — только счётчики**, хеш на день `ev:<kzDay>` (TTL 400 дней), поля: `<e>` (сколько событий такого вида) и измерения: `ls:<lesson>:<via>`, `lr:<lesson>` (продолжения), `lq:<lesson>:<step>/<of>`, `lf:<lesson>`, `la:<lesson>` (сумма acc для среднего), `rc:<choice>`, `tk:<step>:n`, `tk:<step>:w` (неверно или пропуск), `tk:<step>:h`, `ds:<mode>`, `df:<mode>`, `gs:<game>`, `gf:<game>`, `gq:<game>`, `xs:<kind>`, `xf:<kind>`, `pv:<from>`, `pc:<tier>:<period>`, `ts:<from>`, `sc:<item>`, `ho:<where>`, `ob:<step>`, `od:<track>`, `dg:<done>`, `act:<d>`, `br:<code>`, `fb:<kind>`. ## P2. Прогресс для ученика (#52, #66, #71)

### P2.1 Чистая логика `lib/progress.ts` (+ `tests/progress.test.ts`)
- `courseProgress(lessons, opts: { skipBasics?: boolean })` → `{ done, ready, total, ratio }`: `done` — пройденные **готовые уроки на карте** (`UNITS` / `getLesson`; уроки вне карты, например `ns-1-binary`, не считать); `ready` — готовые уроки на карте; `total` — все места на карте (для «ещё K скоро»); `ratio = done / ready`. Раздел «Старт» (`u0`) при `skipBasics` — исключать из обеих величин (тогда 100% достижим без него).
- `unitRows(lessons, skills)` → по разделу: `done`, `ready`, `ratio`, средняя оценка освоения навыков раздела. Переиспользовать `unitProgress` из `components/learn/map.ts` можно, но этот файл не менять (он у другого чата) — если нужно иначе, напиши свою функцию.
- `topicStats(skillDays, skills, days: 7 | 30, now)` → по темам ЕНТ (`SKILLS[].ent`): заданий, точность (`s / n`, null при 0), секунд, оценка освоения, «с подсказкой».
- `topicTrend(skillDays, topic, now, days = 30)` → точки по дням `{ day, n, acc|null }` и изменение: точность последних 7 дней против предыдущих (null, если в любой половине меньше 5 заданий).
- `weakSpots({ skills, skillDays, now }, limit = 5)` → навыки (и темы) с низкой оценкой или падением точности; только при ≥ 3 ответах; ранжирование: `(1 − оценка) × вес темы` (`topicWeight`) + падение тренда + давность; у каждого — ссылка «Потренировать» (`/drill?mode=skill&skill=…` если `hasBank(skill)`, иначе `/drill?mode=topic&topic=…`) и причина (`low` / `fell` / `stale`).
- Тесты: граничные случаи (пусто, мусор, ровно 3 ответа, уроки вне карты, skipBasics, 30 дней).

## P4. Плеер, тренировка, игры, пробник: честные цифры и события (#66, #68, #69)

### P4.1 Плеер урока (`LessonPlayer`)
- **Подсказка:** ответ «с подсказкой», если до ответа на это задание (в фазе «отвечаю») открывалась шторка ИИ в режиме подсказки или «Спросить Бита» (`setAi("hint" | "ask")`) — флаг на шаг, сбрасывается при переходе к следующему шагу; в `AnswerRecord` — `hinted: true`. Разбор после ответа — не подсказка.
- **Пропуск** (`skip()` у решения с фото): после платы за вход создать `AnswerRecord { skipped: true, correct: false, score: 0, given: "", expected, prompt, retry: false, timeMs }`, вызвать `recordAnswer(rec, 0, lessonId)` (стор сам не делает из пропуска ошибку) и положить в `records`; `skippedRef` оставить для итогов.
- **Итог:** `finish()` — точность через `tallyOf`/`accuracyOf` (каркас) в `SessionResult.accuracy` (без заданий — 1), `asked`, `hinted`, `skipped`.
- **Время:** длительность урока и время ответа — активные: `activeMs()` из `lib/active-clock.ts` (разница с моментом старта/показа шага); при продолжении — плюс сохранённый `activeMs` (сохранять в снимок тоже активное время — `run-snapshot.ts`).
- **События** (`track`, каркас `lib/analytics.ts`): `lesson_start` (при входе — один раз за монтирование; `resume` — продолжение), `task` на каждую первую попытку (`ok`, `skip`, `hint`), `lesson_finish` (`acc` — `pct(accuracy)`, `sec`), `lesson_quit` при подтверждённом выходе (окно выхода) с `step` (пройдено шагов) и `of`, `hearts_out` (где: урок/проверка/экстерн) при открытии окна нехватки сердечек. Тренировка (`kind="drill"`) — `drill_start`/`drill_finish` (`mode`), без `lesson_*`; экстерн — тоже `drill_*` с `mode: "extern"`.
- `LessonScreen`: `resume_choice` (продолжить/начать заново).

### P4.2 Итоги (`Results`)
- Точность — та же цифра, что в истории и статистике; под ней мелко: «сам: X из N», «с подсказкой: Y», «пропущено: Z» (что не ноль). Время — активное.
- Цвета: точность по смыслу (зелёный ≥ 80%, янтарный 50–79%, красный < 50%), подсказки — нейтрально.
- Отзыв ИИ после урока (`requestLessonFeedback`) — контекст не менять (промпт не трогаем: ключа для проверки нет).

### P4.3 Игры, пробник, тренировка
- `GameShell`: `game_start` (в `start()`), `game_finish` (`acc` — доля верных в %), `game_quit` (выход крестиком во время игры), `hearts_out`.
- `ExamRun`: `exam_start` (после создания попытки), `hearts_out` (`exam`/`checkpoint`); `ExamResult`: `exam_finish` (`pct` — баллы/максимум) — один раз на попытку.
