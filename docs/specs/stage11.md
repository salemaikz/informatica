# ТЗ этапа 11 — сердечки 2.0 и продолжение урока (v0.10)

> План — `docs/PLAN.md`, «Этап 11». Решения — `docs/DECISIONS.md` #40 (плата за вход), #41 (продолжить или начать заново), #60 (числа: цены входа, цены сердечек, возврат за тренировку).

## Суть этапа

- **Сердечки больше не снимаются за ошибки.** Плата — за вход: урок 1 (большой урок — 2), «Проверить себя» 1, пробный ЕНТ любого вида 1, контрольная раздела 2, экстерн 2, игра 1 (каждый запуск, в том числе «ещё раз»; «урок игрой» стоит как урок). Бесплатно: тренировка, повторение, работа над ошибками, практикум кода, теория, чат.
- **Когда списывается.** Урок, «Проверить себя», экстерн — при **первом ответе** на задание (кнопка «Проверить» или «Пропустить» у задания с фото). Теорию в начале урока можно читать бесплатно. Пробный ЕНТ и контрольная — по кнопке «Начать» (продолжение уже начатой попытки — бесплатно). Игра — по кнопке «Играть».
- **Незаконченный урок сохраняется** (только режим «Учиться»): позиция, очередь, ответы, XP, время; до 5 уроков, 14 дней. При возврате — экран «Продолжить / Начать заново». Вернулся не позже 20 минут после последнего действия и вход уже оплачен — продолжение бесплатно; иначе — снова цена входа. «Начать заново» стоит всегда.
- Числа и правила — в `src/lib/economy.ts` и `src/lib/lesson-run.ts`, не дублировать их в коде и текстах: подставлять из констант.

## Общие правила пакетов

- **Свои файлы.** У каждого пакета — список. Чужие и общие файлы не правь: нужна правка — опиши в отчёте (файл, что и зачем). Файлы каркаса (`lib/economy.ts`, `lib/lesson-run.ts`, `lib/store.ts`, `components/economy/{HeartCost,EntryGate,OutOfHearts,HeartsBar,shop-helpers}.*`) — только главная модель.
- **Строки** — только в словари своего пакета, каждый ключ `{ ru, kk }`, префикс ключей — как у словаря. Без глаголов с родом («урок не закончен», а не «ты не закончил»). Без эмодзи. ҰБТ в казахском. Сердечко по-казахски — «жүрек», чипы — «чиптер».
- **Числа в текстах** — подстановкой из констант (`{n}`), не литералами: цены и правила ещё могут поменяться.
- **Ключа OpenAI нет** — `npm run review:kk` недоступен. Казахский пиши литературно по глоссарию `docs/ENT.md` §4; вычитает главная модель.
- **Проверки:** `npx tsc --noEmit` (перед этим один раз `npx next typegen`), `npx eslint <свои файлы>`, `npx vitest run <свои и затронутые тесты>`; в конце — полный `npx vitest run`. **`npm run build`, `npm run dev`, e2e не запускай** — их запускает главная модель (машина общая). e2e-сценарии пиши и правь, но не запускай.
- **Рабочая копия:** если в worktree нет `node_modules` — `cp -al /home/user/informatica/node_modules ./node_modules` (жёсткие ссылки, не symlink).
- **React 19:** без синхронного `setState` в эффектах; время в рендере — `useNow()`; списание и сохранение — в обработчиках (клик, «Проверить»), не в эффектах (в режиме разработки эффекты срабатывают дважды — двойное списание).
- **Коммит** — в своей ветке worktree, одним коммитом, сообщение `v0.10: <что сделано>` + строки атрибуции из среды. Не пушить.
- **Отчёт** (до 25 строк): файлы, что проверено, что не сделано, правки для чужих файлов, новые и изменённые kk-строки (списком ключей).

## A. Урок: плата при первом ответе и продолжение (#40, #41)

### A1. Новые свойства `LessonPlayer`
```ts
/** Цена входа в сердечках (#40): списывается при первом ответе (или «Пропустить»). Нет или 0 — бесплатно (тренировка). */
entryCost?: number;
/** Продолжить сохранённое прохождение (#41) — только урок в режиме «Учиться». */
resume?: LessonRun;
/** Сохранять прохождение после каждого шага (#41) — только урок в режиме «Учиться». */
saveRun?: boolean;
```
Экстерн (`DrillScreen`, пакет B) передаёт `entryCost={ENTRY_COST.extern}` без сохранения — плеер должен это поддерживать для `kind="drill"`.

### A2. Плата при первом ответе
1. Состояние «вход оплачен»: при `resume` — `runPaid(resume, Date.now())` (вычислить один раз при монтировании), иначе `false`; момент оплаты (`paidAt`) хранить для сохранения.
2. В `check()` (до проверки ответа и до `spendAi("photo")`) и в `skip()`: если `entryCost > 0` и вход не оплачен — `useApp.getState().payEntry(entryCost)`. `ok` — вход оплачен, продолжаем. Не `ok` — открыть `OutOfHearts` (шторка, `need={entryCost}`), ответ не проверять; `onResume` — закрыть шторку (ученик нажмёт «Проверить» ещё раз). Шапка (`HeartsBar`) сама покажет «−1»/«−2».
3. Убрать старую логику: состояние `heartLost` и плашку «−1 сердечко» в панели ответа; блок в `next()`, открывающий шторку перед новым заданием (сердечки больше не кончаются посреди урока); неиспользуемые импорты. `HeartsBar` в шапке — когда `entryCost > 0`.
4. Повтор ошибки в конце урока, подсказки, «Спросить Бита» — без платы (только первый ответ сессии).

### A3. Сохранение (при `saveRun`)
1. Снимок `LessonRun` (тип — `lib/lesson-run.ts`) сохранять через `useApp.getState().saveLessonRun(run)` **в обработчиках**:
   - после ответа (`apply`) — шаг считается пройденным: `pos` = текущая позиция + 1, очередь — уже с добавленным повтором ошибки, `records`/`xp`/`combo`/`maxCombo`/`done` — новые значения (посчитать локально: `setState` асинхронный);
   - при переходе к следующему шагу (`next()`, теория и разборы) — `pos` = новая позиция;
   - после завершения урока не сохранять (сохранение удалит `finishSession`).
2. Поля: `sig` = `lessonSig(steps)`, `queue` = `{ id: step.id, retry }[]`, `skipped`, `activeMs` = время с начала прохождения (при продолжении — от сохранённого `activeMs`), `xpFactor` (зафиксирован на входе), `chipsEarned` = `wallet.earned` сейчас − на старте прохождения, `cost` = `entryCost`, `startedAt` (первого входа), `updatedAt` = сейчас, `paidAt` (или `null`).
3. Удобно вынести сборку снимка в чистую функцию (`components/lesson/run-snapshot.ts` + тест `tests/lesson-run-player.test.ts`).

### A4. Продолжение (при `resume`)
1. Начальное состояние — из сохранения: очередь `restoreQueue(resume, steps)` (null — начать с нуля), `pos`, `done`, `records`, `xp`, `combo`, `maxCombo`, `skipped`, `xpFactor`; «заработано чипов на старте» = `wallet.earned − resume.chipsEarned` (итоги покажут чипы за весь урок); время урока продолжает `activeMs`.
2. Если `pos >= queue.length` (все шаги пройдены, не нажато «Продолжить» на последнем) — вместо шага небольшой экран «Все шаги пройдены» (маскот, кнопка «Посмотреть итоги» → `finish(...)`). Без платы.

### A5. `LessonScreen` (режимы «Учиться» и «Проверить себя»)
1. «Учиться»: сохранение `usableRun(useApp.getState().lessonRuns[id], lesson, Date.now())` — прочитать **один раз** при монтировании (`useState(() => …)`). Есть — сначала экран `ResumeLesson`; нет — сразу плеер.
2. `ResumeLesson` (новый, полноэкранный, как экран «Сердечки закончились» по стилю): маскот, название урока, «Урок не закончен», полоска прогресса и «Шаг N из M» (по `done`/числу шагов), набранные XP; кнопки:
   - «Продолжить» (основная) — со значком `HeartCost` цены входа, если `!runPaid(run, now)` и впереди есть задания; иначе без цены;
   - «Начать заново» (вторичная) — со значком `lessonCost(lesson)`; по нажатию `clearLessonRun(id)` и плеер с нуля;
   - «Назад» → `/learn`.
3. Вход проверяет `EntryGate` (`need` = цена входа или 0, если продолжение уже оплачено; `exitHref="/learn"`, `theoryHref=/theory/<id>`). Старый `HeartsGate` в `LessonScreen` заменить на `EntryGate`.
4. Плееру: «Учиться» — `entryCost={lessonCost(lesson)}`, `saveRun`, `resume` (если выбрано «Продолжить»); «Проверить себя» — `entryCost={ENTRY_COST.check}`, без сохранения. Смена «Продолжить»/«Начать заново» должна пересоздавать плеер (`key`).

### A6. Тексты
- Окно выхода из урока при `saveRun`: «Прогресс сохранится — урок можно продолжить позже.» (новый ключ, старый текст «Прогресс этого урока не сохранится» — для «Проверить себя» и тренировок).
- `ResumeLesson`: заголовок, «Шаг {n} из {m}», «Продолжить», «Начать заново», подпись под «Начать заново»: «Сохранённый прогресс урока сбросится», подсказка о цене: «Вернуться в течение 20 минут — бесплатно» (минуты — из `RUN_GRACE_MS`).

### A7. Проверка
- Юнит: снимок прохождения и восстановление (если вынесено).
- e2e `e2e/hearts.spec.ts` (не запускать, главная модель запустит): (1) 5 сердечек → урок → теория без списания → первый ответ → 4; ошибка во втором задании — по-прежнему 4; (2) выйти посреди урока → снова открыть → экран «Продолжить» → шаг сохранён, сердечки не списаны повторно; «Начать заново» → с первого шага; (3) 0 сердечек → «Сердечки закончились» на входе. Состояние стора задавать через `localStorage` до загрузки страницы — как в существующих e2e (`e2e/economy.spec.ts`, `e2e/smoke.spec.ts`).

**Готово:** урок не снимает сердечки за ошибки, списывает вход один раз при первом ответе, выход и возврат продолжают с того же шага, перезагрузка в пределах 20 минут не списывает повторно; `tsc`, `eslint`, `vitest` чистые.

## B. Другие входы и значки цены (#40)

1. **Игры** (`GameShell`): цена `entryCost("game", lesson)`. По «Играть» (и при каждом новом запуске, в том числе «ещё раз») — `payEntry(cost)`; не хватает — шторка `OutOfHearts` (`need`), после покупки — запуск. На кнопке «Играть» — `HeartCost variant="solid"`; во вступлении короткая строка «Каждый запуск игры стоит сердечко» (у «урока игрой» — цена урока, подстановкой).
2. **Пробный ЕНТ и контрольная** (`ExamRun`, экран вступления): цена — `ENTRY_COST.checkpoint` для `kind === "unit"`, иначе `ENTRY_COST.exam`. По «Начать»: сначала `canAfford` (не хватает — шторка `OutOfHearts`, после покупки — снова «Начать»), затем создание попытки, затем `payEntry` (порядок важен: сбой IndexedDB не должен съесть сердечко). Продолжение начатой попытки — бесплатно. На кнопке «Начать» — `HeartCost variant="solid"`; в правила добавить строку «Попытка сохраняется — продолжить её можно без новых сердечек».
3. **Экстерн** (`DrillScreen`, `mode=extern`): `EntryGate need={ENTRY_COST.extern}` на входе, плееру — `entryCost={ENTRY_COST.extern}` (плата при первом ответе — делает плеер, пакет A). Другие режимы тренировки — бесплатно, без изменений.
4. **Значки цены** (`HeartCost`) на входах:
   - `LessonSheet` (шторка урока на карте): «Учиться» — `lessonCost(lesson)`, «Проверить себя» — 1, игры — `entryCost("game", lesson)`, пробник по теме — 1; «Теория», «Конспект» — без значка. Под карточками режимов одна строка мелким: «Сердечко списывается при первом ответе. Теория — бесплатно».
   - `ExamHub` (карточки мини/полного/по теме) — `ENTRY_COST.exam`; `CheckpointNode` — `ENTRY_COST.checkpoint`; `UnitSection` (кнопка экстерна) — `ENTRY_COST.extern`; `EntMap` (кнопка пробника по теме) — `ENTRY_COST.exam`; карточки игр на `/practice` — `ENTRY_COST.game`.
   - Значок не должен ломать вёрстку на 360 px (проверь, что строки не переносятся посреди слова; при нехватке места значок — в отдельной строке).
5. e2e: сценарии запуска игр (`e2e/games.spec.ts`), мини-ЕНТ (`e2e/stage3.spec.ts`), контрольной (`e2e/v08.spec.ts`) — с полным запасом сердечек они должны проходить как раньше; добавь проверку, что после «Играть» сердечек на одно меньше (в одном тесте) и что при 0 сердечек «Начать» пробника показывает «Сердечки закончились».

**Готово:** каждый платный вход списывает ровно свою цену один раз, бесплатные — ничего; значки цены видны на всех входах; `tsc`, `eslint`, `vitest` чистые.

## C. Магазин, тарифы, тексты экономики (#40, #60)
