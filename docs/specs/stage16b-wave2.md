## A. Дорожка школы (главная модель: модель данных; исполнитель: экран)

1. **Группы** — чистый модуль `src/lib/school-path.ts`: для плана класса (`schoolPlan(grade, direction)`) — разделы по порядку,
   у раздела: готовые уроки (без повторов внутри класса, в порядке тем), навыки этих уроков (из каталога), темы «скоро».
   `schoolGroups(plan): SchoolGroup[]` — `{ id: "sch:<sectionId>", sectionId, quarter, lessons, soon: SchoolTopic[] }`.
2. **Узлы**: урок; «Упражнения» после каждого раздела с готовыми уроками (`practice:sch-<sectionId>`, 12 заданий из банков навыков раздела,
   доли 50/30/20 как в ЕНТ: текущий раздел / три предыдущих раздела класса / раньше, бесплатно); «Повторение» в конце каждой четверти
   (`recap:sch-<grade>[<dir>]-q<N>`, 15 заданий по всем разделам четверти и раньше, бесплатно); «Тест по разделу» в конце раздела
   (15 заданий из банков навыков раздела, уровни B–C, 2 сердечка при старте, ≥ 80% — засчитать непройденные уроки раздела с заданиями в варианте).
   Темы «скоро» — под разделом мелкой серой строкой «Скоро: …», не узлами.
3. **Тренировка**: `lib/course-mix.ts` — `buildPractice` / `buildRecap` принимают последовательность групп (по умолчанию `COURSE_GROUPS`);
   для школы — группы класса. `DrillScreen`: `?mode=practice&node=practice:sch-…`, `?mode=recap&node=recap:sch-…`,
   `?mode=sectiontest&node=…` (новый режим: старт-экран с ценой, как мини-тест из волны 1). `lib/course-nodes.ts` — id школьных узлов
   проходят `ID_RE`; `MAX_COURSE_NODES` поднять, если не хватит.
4. **Экран**: `components/school/SchoolPath.tsx` — дорожка как у ЕНТ (`components/learn/PathView`, `UnitSection`, `LessonNode`, `PracticeNode`
   — переиспользовать, а не копировать; если компоненты завязаны на `Unit`, сделать адаптер «раздел класса → unit-подобный объект»).
   Над дорожкой — выбор класса (как сейчас) и карточка прогресса. Переключатель «Дорожка | Темы» (темы — нынешний аккордеон).
   «Продолжить» — следующий урок школьной дорожки (или начатый — волна 1).
5. Тесты: `tests/school-path.test.ts` — группы каждого класса (нет пустых, нет повторов уроков внутри класса, узлы с корректными id),
   сборка упражнений/повторения/теста по школьным группам (задания только из навыков нужных разделов), общий прогресс со ЕНТ не ломается
   (`tests/school.test.ts`).

## B. Тренажёры (каждый — отдельный исполнитель, контракт задаёт главная модель)

Тренажёр = новый вид шага-задания `type: "trainer"` в уроке (и площадка в практикуме позже). Контракт — `src/trainers/types.ts`
(делает главная модель): `TrainerStep { type: "trainer"; trainer: TrainerId; task: <данные задачи>; prompt: L; explanation: L; hint; skill; level }`,
ответ — `{ type: "trainer"; data }` (что сделал ученик: программа робота, пиксели, фигуры, код); **верность считает код** —
`check(task, data): boolean` в чистом `logic.ts` тренажёра (тот же код — в плеере и в тестах). Плеер грузит тренажёр по требованию (`import()`).
Папка тренажёра: `src/trainers/<id>/{types.ts, logic.ts, View.tsx, strings.ts}` + `tests/trainers-<id>.test.ts`.

1. **Робот** (`robot`, 5 кл.: «Роботы вокруг нас», алгоритмы, датчики): поле N×M (до 8×8), стены, цель, предметы; команды — «вперёд», «налево»,
   «направо», «повторить N раз { … }», «пока впереди свободно { … }», «если датчик видит стену/линию — …». Программа собирается из плашек
   (крупные кнопки, телефон), «Пуск» показывает пошаговое движение (скорость, «Стоп», «Шаг»), проверка — дошёл до цели, собрал предметы,
   не врезался, ограничение числа команд (для задач «короче»). Задачи: 12–15 штук по возрастанию (линейные → циклы → условия с датчиком).
2. **Графический редактор** (`pixels`, `vector`, 5 кл.: растровые и векторные изображения, кривые): `pixels` — сетка до 16×16, палитра до 8 цветов,
   карандаш, заливка, ластик; задачи «нарисуй по координатам», «закрась по коду (0/1 → чёрный/белый)», «сколько бит нужно на рисунок»,
   «увеличь — что станет с краями». `vector` — фигуры (отрезок, прямоугольник, окружность, ломаная, кривая Безье с 1 контрольной точкой)
   по координатам на сетке; задачи «построй фигуру», «измени масштаб — фигура не теряет чёткость», «найди отличие растра и вектора».
   Проверка — сравнение результата с целевым (пиксели; фигуры с допуском). 10–12 задач.
3. **Игровой цикл** (`pygame`, 9 кл.: PyGame, фон и персонажи, анимация, условия): Python-песочница практикума (`lib/ide/python`, Pyodide —
   только динамической загрузкой) + маленький модуль `game` (не настоящий PyGame): `game.rect/circle/text/sprite`, `game.key_pressed`,
   цикл `for frame in game.frames(60)` / функция `update()`; рисование на canvas, кадры по таймеру. Задачи: нарисовать сцену, сдвигать персонажа,
   анимация по кадрам, столкновение со стеной (условие), счёт. Проверка — по журналу кадров (положения объектов), не по картинке. 8–10 задач.
   Чужой код — только в песочнице (Worker), как в практикуме.
4. Каждый тренажёр: ru/kk строки в `strings.ts`, доступность (кнопки ≥ 44 px, `aria-label`), обе темы, `useReduceMotion`, телефон 360 px.

(песочница HTML/JS практикума); 10 ОГН видео (4: теория + задания + ссылки), сайт: дизайн, карта, главная, контент, мультимедиа, публикация,

Каждый урок — по `docs/RULES.md` §4 и `docs/CONTENT_GUIDE.md`: 14–18 шагов, карточки ≤ 100 слов, рисунок у половины карточек, задания A/B/C,
банк навыка (`src/lib/bank/school-*.ts`), навык `school.*`; привязка к теме в `school-program.ts` и регистрация — главная модель.
Казахский — вычитка, пометка «вычитано моделью, носителем — нет».
