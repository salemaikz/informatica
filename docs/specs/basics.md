# ТЗ: раздел «Старт: компьютер с нуля» и иллюстрации (v0.7)

> Отзыв пользователя (2026-10-03): «человек может вовсе не знать тем — начинать надо с устройства компьютера, базовых понятий, сочетаний клавиш, операционных систем, внутренностей компа, как работают вычисления, как устроен процессор, память, какие компоненты в ПК; а у нас сразу и без адекватного объяснения про биты, байты; мало примеров, где используется, как выглядят носители информации, мало иллюстраций и картинок». Решение #36.

## 1. Что делаем

- Новый **первый раздел курса `u0` «Старт: компьютер с нуля»** — 8 коротких уроков для полного новичка (уже на карте в `src/content/course.ts`, навыки `base.*` — в `src/content/skills.ts`).
- **Новые иллюстрированные сцены** (SVG, светлая и тёмная тема): рисунки деталей, носителей и устройств, системный блок изнутри, цикл процессора, клавиатура, объёмы файлов, дерево папок, «слои». Типы уже в `src/lib/types.ts` (`Scene`: `hardware`, `pc-inside`, `cpu-cycle`, `keyboard`, `sizes`, `files`, `layers`), проверка данных — `tests/validate.ts`, заглушки компонентов — `src/components/scenes/*Scene.tsx`.
- Ученик, который знает основы, пропускает раздел (выбор в онбординге, `profile.skipBasics`) — делает главная модель.

## 2. Уроки раздела (каждый 5–8 минут, тема «на знание»: 60% объяснения, 40% заданий)

Методика — `docs/CONTENT_GUIDE.md` и `docs/specs/content.md` (сюжет `story` с Битом → карточки `theory` со сценой → разборы `worked` → ловушка → `cloze` → 4–7 заданий A→B→C → задание ЕНТ → конспект). **Главное для этого раздела:**
- Объяснять **через знакомое и повседневное**: телефон, ноутбук, банкомат, касса в магазине, умные часы, игровая приставка, машина. В каждом уроке — карточка «Где это встречается» (сцена `hardware` или `cards`).
- **Каждая новая вещь — с картинкой** (сцена `hardware`, `pc-inside` и др.), минимум 6 шагов со сценой на урок. Не стена текста: 2–4 коротких абзаца на карточку.
- Аналогии: процессор — повар/мозг, оперативная память — рабочий стол, диск — шкаф, ОС — дирижёр/администратор.
- Числа и размеры — реальные и проверяемые (фото с телефона ≈ 3–5 МБ, песня MP3 ≈ 4–8 МБ, фильм ≈ 1,5–4 ГБ, телефон 64–256 ГБ, флешка 16–128 ГБ, DVD 4,7 ГБ, CD 700 МБ).
- Термины на казахском — по глоссарию НЦТ (`docs/ENT.md`, раздел 4): процессор, жедел жады (ОЗУ), тұрақты жад, қатқыл диск, ақпарат тасығыш, енгізу/шығару құрылғылары, операциялық жүйе, файл, бума (папка), кеңейтім, пернетақта.

2. `src/lib/bank/<id>.ts` — `export const BANKS: SkillBank[]` через `poolBank` (≥ 15 вопросов, по ≥ 5 на уровень; ≥ 10 утверждений «верно/неверно»; ≥ 8 пар; можно `short`). Это кормит тренировки, игры и «сдать экстерном».
3. `src/content/ent/<id>.ts` — `export const ITEMS: EntItem[]`: ≥ 10 single, ≥ 3 multi, ≥ 3 match, уровни A, B, C; `id` начинается с `<id>:`; тема из колонки «Темы ЕНТ».

## 3. Иллюстрации (новые сцены)

Общие требования: SVG внутри React-компонента, `viewBox` с адаптивной шириной (на 360 px читается, на десктопе не больше ~560 px), цвета — **только CSS-переменные темы** (`var(--surface)`, `var(--border)`, `var(--text)`, `var(--muted)`, `var(--primary)`, `var(--success)` …), без внешних картинок и шрифтов; подписи — через `useT()/l()`; «Меньше анимаций» уважать (анимации только CSS/motion с учётом `useReduceMotion`); `role="img"` и `aria-label`. Стиль — **плоская «учебниковая» иллюстрация**: узнаваемые формы с характерными деталями (у HDD — круглая пластина и головка-коромысло, у SSD — плата с микросхемами, у ОЗУ — длинная планка с чипами и ключом, у процессора — квадрат с «ножками»/контактами, у флешки — USB-разъём), 2–3 оттенка на предмет, мягкие тени.

|---|---|---|

Названия — словарь в файле сцены (`hardware/names.ts`, `{ ru, kk }`). Каждый рисунок — отдельная функция в `src/components/scenes/hardware/*.tsx` |
| `pc-inside` | Открытый системный блок сбоку: материнская плата, процессор под кулером, планки ОЗУ, видеокарта, SSD/HDD, блок питания, вентиляторы, порты на задней стенке; выноски с подписями; `highlight` — подсветка (остальное приглушено) | Один большой рисунок; на 360 px подписи не наезжают (выноски слева/справа) |

| `keyboard` | Упрощённая клавиатура (ряды с основными клавишами: Esc, F1–F12 мелко, цифры, буквы QWERTY с русскими буквами мелко, Tab, Caps, Shift, Ctrl, Win, Alt, пробел, Enter, Backspace, стрелки); подсветка `keys` и под клавиатурой сочетание крупно «Ctrl + C» | Названия клавиш — латиницей как на клавиатуре; на 360 px клавиатура целиком, мелкие клавиши можно упростить |

| `files` | Дерево папок (иконки папка/файл, отступы), выделение `active` (путь через «/»), под деревом — путь в стиле Windows `C:\…` | Иконка файла по расширению (документ, картинка, музыка, видео, код, архив) |
| `layers` | Стопка слоёв (2–6) сверху вниз, иконки, `highlight`, ось слева со стрелкой и подписями `axis.top`/`axis.bottom` (например «быстрее» / «больше») | Для «пользователь → программы → ОС → железо» и «регистры → кэш → ОЗУ → SSD → HDD» |

Чистая логика (форматирование размеров, разбор пути, раскладка) — в `.ts`-модулях рядом с компонентами, с тестами в `tests/scenes-basics.test.ts`.
