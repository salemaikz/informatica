## 2. Набросок ТЗ (предложение главной модели прошлого чата; решать в новом чате)

### 2.1 Обучение заканчивается началом урока

**Сейчас (v0.18, `src/lib/guide.ts` → `GUIDE_SCENES`):**
- `welcome` на «Учиться» (нет пройденных уроков): привет → карточка урока (`next-lesson`) → сердечки в шапке (`hdr-hearts`) →
  «Нажми «Начать»» (`continue`, шаг-нажатие) — открывается урок;
- `lesson-first` в первом уроке: сердечки → полоска → «Выбери ответ» → «Нажми «Проверить»» → значок ИИ («если трудно — нажми сюда»);
- `after-first` на итогах первого урока: опыт → чипы → огонь → «Нажми «Продолжить»»;
- `nav` на «Учиться» после первого урока: карточка урока → нижние вкладки → кнопка Бита (пузырь из неё) → **«нажми на чипы» → магазин**,
  где начинается `page-shop`. **Обучение заканчивается в магазине, а не уроком** — это и просит исправить владелец.

**Предложение:**
- Всё «знакомство с приложением» — **до** первого урока, в сцене `welcome`: привет → карточка урока → шапка одним шагом (огонь, сердечки,
  чипы — объединённая рамка; про чипы: «валюта, их тратят в магазине») → нижние вкладки → кнопка Бита (пузырь из неё, как сейчас в `nav`) →
  **последний шаг — «Начнём! Нажми «Начать»»** (нажатие, открывается урок). Шаг «нажми на чипы → магазин» убрать (магазин объяснит
  `page-shop` при первом заходе).
- После первого урока: `after-first` (опыт, чипы, огонь) → «Нажми «Продолжить»» → на «Учиться» **одна** реплика у карточки урока:
  «Следующий урок — здесь. Нажми «Начать»» (нажатие) → урок. Сцену `nav` убрать (её шаги переехали в `welcome`). Итог: любое обучение
  заканчивается нажатием «Начать урок».
- Старые ученики: у кого `nav` уже показан — ничего не показываем; у кого `welcome` показан, а `nav` нет — показать короткую версию
  (вкладки, кнопка Бита, «Нажми «Начать»»). Решить в новом чате.
- `tourBlocking` (окна тарифов, уведомлений, кейс ждут конца обучения) сейчас смотрит на `nav` — перевесить на новую последнюю сцену.
- Школьный трек: та же логика, «Начать» — кнопка следующего урока класса (`GradeProgressCard`, метки `next-lesson`/`continue` уже есть).

### 2.2 Внутри урока: что за значки калькулятора и ИИ

**Шапка урока** (`src/components/lesson/LessonPlayer.tsx`, ~строки 795–835): крестик, полоска (`lesson-progress`), огонь, сердечки
(`lesson-hearts`), **значок ИИ** (`lesson-ask`: искорка `Sparkles` на фиолетовом, с числом — сколько бесплатных вопросов осталось,
`AiFreeDot`), **значок инструментов** (`ToolboxButton` — открывает панель «Инструменты»: калькулятор как на ЕНТ, перевод 2/8/10/16 с шагами,
единицы, степени двойки, черновик; **метки `data-tour` нет — добавить `lesson-tools`**).

**Предложение для сцены `lesson-first`:** сердечки → полоска → **инструменты** («Это инструменты: калькулятор как на ЕНТ, перевод
систем счисления, черновик. Понадобится посчитать — нажми.») → **ИИ** («А это я — ИИ-помощник. Застрял — нажми: подскажу, но ответ
не назову. Цифра — сколько бесплатных вопросов осталось.»; без цифры — без последней фразы) → «Выбери ответ» (нажатие) →
«Нажми «Проверить»» (нажатие). Старый последний шаг про ИИ убрать (переехал выше). Тексты — `src/i18n/parts/guide.ts` (ru/kk, без глаголов
с родом). Проверить: режим «Проверить себя»/тест (значок ИИ до ответа скрыт — шаг пропускается), «Безлимит», школьный трек, 360×640.
