## Как работаем (пользователь это просил)
- **Распределение моделей** (`CLAUDE.md`): главная модель — ТЗ, архитектура, промпты, интеграция, финальная проверка; `sonnet` — работа по ТЗ (параллельно, у каждого свои файлы); `haiku` — механика; после исполнителя — **строгий ревьюер (`opus`), который сам исправляет найденное** (в волне 3 — около 90 реальных дефектов).
- Большие задачи — через `Workflow` (у пользователя включён ultracode): ТЗ в `docs/specs/*.md` → `pipeline(модули, исполнитель, ревьюер)`; одновременно не больше двух workflow (4 ядра).
- Общие файлы (`dict.ts`, `store.ts`, `AppShell`, `Providers`, `games/components.ts`, `docs/*`) правит только главная модель. Для новых разделов заранее создаём пустой `src/i18n/parts/<модуль>.ts` и подключаем в `dict.ts`.
- **Каждый этап:** ТЗ → исполнители → тесты и скриншоты → выкладка → пользователь смотрит → правки. Этап закрыт, только когда пользователь его принял.
- **Документация обязательна:** `CHANGELOG`, `ROADMAP`, `DECISIONS` (сейчас #1–#37), `ARCHITECTURE`, `PLAN`. Изменения промптов ИИ — отдельной строкой и с проверкой живыми запросами на ru и kk.
- **Казахский:** носителя нет; после новых текстов — `npm run review:kk` (нужен ключ OpenAI). Термины НЦТ (`docs/ENT.md`, раздел 4) важнее советов модели. Окончания после чисел — только `kkSuffix`.
- **Перед коммитом:** `npm run typecheck && npm run lint && npm test && npm run build`, плюс e2e. Пока работают исполнители, готовую часть проверяем в отдельной копии, чтобы не выложить незаконченное:
  ```bash
  git worktree add <scratch>/wt HEAD && cp -al node_modules <scratch>/wt/node_modules
  ```
  (symlink на `node_modules` Turbopack не принимает.) Next 16 не даёт запустить второй `next dev` в той же папке — исполнители поднимают сервер из копии.
- **Облако Claude Code:** сервер с ИИ — с `NODE_USE_ENV_PROXY=1`; Chromium — `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`; серверы останавливать по PID, не `pkill -f next`; внешний CDN в Playwright — через `proxy: { server: process.env.HTTPS_PROXY }` и `ignoreHTTPSErrors`, а нестабильный CDN подменять локальной копией (пример — `scripts/out/wave3/python/review/review.mjs`, папка в git не попадает).
- Пользователь пишет по-русски коротко и неформально. Отвечать по-русски, без жаргона, по делу.

## Известные ограничения
- Прогресс только на устройстве; лимит ИИ — по IP в памяти процесса (исправит этап 5).
- Казахские тексты этапа 3 и волны 3 вычитаны только моделями; `npm run review:kk` не запускался (в облачной среде не было ключа).
- Изменённые промпты (лестница подсказок, кэш, строка про кризис) не проверены живыми запросами.
- Python требует интернет при первом запуске (~10 МБ с jsDelivr).
- Напоминания — без сервера (пока приложение открыто; Android с установленным приложением — и в фоне).
- Правовые страницы — черновики, юристом не проверены.
- Видео к новым урокам нет — ждём выбор стиля.
- Тестовый ключ OpenAI когда-то передавался в чате — для продакшена нужен новый ключ.
