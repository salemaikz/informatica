# reference/ — эталонные файлы из Informatica

Снимок кода Informatica на 2026-10-03. Это **образцы**, а не готовый код для математики.

## Как пользоваться

- **Можно взять почти как есть:** дизайн-токены и шрифты, UI-компоненты, анимации, `cn`, `useT`, звуки, вибрация, геймификация, освоение навыка, лимиты, обрезка и клиент OpenAI на сервере, Markdown-рендер, хук стриминга, конфиги.
  - Меняем только название, ключ `localStorage` и тексты.
  - В `globals.css` ничего не меняем: цвета и их смысл должны остаться теми же.
  - Можно заменить, если захочется свой фирменный оттенок: `--primary` и `--primary-*`.
- **Взять как образец и переписать под математику:**
  - `lib/types.ts`: типы шагов `bits` и `ladder` относятся к информатике;
  - `lib/check.ts`, `lib/evaluate.ts`: для математики нужны числа, дроби, запятая;
  - `server/prompts.ts`: термины информатики заменить на математические, см. `docs/AI.md`;
  - `i18n/dict.ts`;
  - `lib/store.ts`;
  - `Mascot.tsx`: вместо «Бита» — «Пи»;
  - уровни в `gamification.ts`: в Informatica их названия «Бит», «Байт» и т. д.
- Codex должен **читать отсюда нужный файл по ссылке из docs**, а не весь каталог целиком. Так тратится меньше токенов.

## Что где

| Файл | Зачем |
|---|---|
| `src/app/globals.css` | Все цветовые токены (светлая и тёмная темы), Tailwind v4 `@theme`, базовые стили |
| `src/app/layout.tsx`, `manifest.ts` | Шрифты, метаданные, PWA-манифест |
| `src/components/ui/*` | Button, Card, Modal, Pill, ProgressBar/Ring |
| `src/components/motion/*` | Анимации: пресеты пружин, встряска, всплеск XP, огонёк комбо, «меньше анимаций» |
| `src/components/mascot/Mascot.tsx` | Маскот на SVG с настроениями — образец для «Пи» |
| `src/components/app/AppShell.tsx` | Навигация: нижнее меню на телефоне, боковое на ПК |
| `src/lib/*` | Чистая логика: типы, проверка, освоение, геймификация, ЕНТ-оценка, звук, вибрация, стор |
| `src/i18n/*` | Двуязычие на уровне типов |
| `src/server/*`, `src/app/api/ai/*` | ИИ: клиент, промпты, лимиты, обрезка, маршруты |
| `src/components/ai/*`, `src/components/Markdown.tsx`, `src/lib/ai*.ts` | ИИ на клиенте: стриминг, панель подсказки и разбора, безопасный Markdown |
| `src/games/types.ts` | Контракт мини-игры |
| `scripts/*` | Вычитка казахского сильной моделью, озвучка TTS |
| `.env.example`, `*.config.*`, `tsconfig.json`, `package.json` | Настройки и зависимости |
