## 2026-10-03 · v0.0.0 — набор правил получен

<!-- Дату поменяй на день, когда набор положен в репозиторий. 2026-10-03 — дата снимка набора. -->

### Как делали
- Набор подготовлен в репозитории образца Informatica (папка `docs/math-kit/`). Источники:
  - код и документы Informatica: снимок 2026-10-03, версия образца v0.4.0 (этапы 0–2 образца, 467 юнит-тестов и 6 e2e);
  - спецификации и демоверсии ЕНТ-2026 по математике и математической грамотности (НЦТ);
  - документация OpenAI Codex и OpenAI API на 2026-10-03.
- Кода приложения Matematika ещё нет.

### Сделано
- В корень репозитория положены:
  - `README.md` — «начни отсюда» для владельца;
  - `AGENTS.md` — правила для Codex;
  - `reference/` — эталонные файлы Informatica, только для чтения, в сборку не входят.
- В `docs/`:
  - продукт — `CONCEPT.md`;
  - дизайн — `DESIGN.md`;
  - код — `ARCHITECTURE.md`;
  - уроки — `LESSON_METHOD.md`;
  - ИИ — `AI.md`;
  - игры — `GAMES.md`;
  - экзамен — `ENT_MATH.md`;
  - план — `ROADMAP.md` (этапы 0–11);
  - промпты для Codex — `PROMPTS.md`;
  - процесс — `WORKFLOW.md`;
  - журналы — `CHANGELOG.md`, `DECISIONS.md`, `HANDOFF.md`.
- **Решения по умолчанию** — `docs/DECISIONS.md`:
  - #1–#20 — решения Informatica, переписанные для математики (номера совпадают с образцом);
  - #21 и дальше — новые: название и ключ хранилища, маскот «Пи», два трека, формулы Unicode + KaTeX, запятая, проверка по значению, математическая клавиатура, разработка в Codex, ветки и выкладка, ключ и лимиты, казахские термины, контент с прогрессом, геймификация, картинки-«крючки» (по умолчанию нет).
  - Владелец подтверждает или меняет их на этапе 0 (П-0).

### Промпты ИИ
- Промптов приложения ещё нет. Образец — `reference/src/server/prompts.ts`. Что поменять для математики (KaTeX вместо «без LaTeX», термины, «Пи» вместо «Бита») — `docs/AI.md`.

### Модели ИИ
- По умолчанию, как в образце:
  - `OPENAI_MODEL_FAST` = `gpt-5.4-nano`;
  - `OPENAI_MODEL_TUTOR` и `OPENAI_MODEL_VISION` = `gpt-5.4-mini`;
  - `OPENAI_MODEL_REVIEW` = `gpt-5.5` — только офлайн; в API `gpt-5.5` остаётся.
- `gpt-5.4-nano` объявлен устаревшим: отключение в API 01.04.2027. Кандидат на замену — `gpt-6-luna`, после живой проверки на математике ru/kk (`docs/DECISIONS.md`, #6).

### Казахский
- Казахские строки в документах набора — **черновики**: названия уровней, игр, достижений; термины с пометкой «проверить» в `docs/ENT_MATH.md`, раздел 4.
- Перед попаданием в приложение — `npm run review:kk`. Носителем — нет.
