# Новые варианты визуалов и видео · 07.10.2026

Запрос владельца: добавить разные визуальные варианты и видео как для уроков, так и для Instagram. Новые материалы дополняют пробы 06.10.2026; решение о публикации остаётся за владельцем.

## Что подготовлено

| Группа | Варианты | Формат |
|---|---|---|
| Уроки | Полка с числами, живой конспект, детектив ошибки | 3 композиции по 30 секунд, 1080×1080, RU/KK |
| Instagram | Мини-загадка, комикс с Битом, знакомство с сервисом | 3 композиции по 20 секунд, 1080×1920, RU/KK |
| Оформление | Бумажный конспект, мастерская Бита, яркий комикс | 3 направления: урок + кейс + косметика + обложка, RU/KK |

Все уроки объясняют один пример: `a = [4, 7, 9]`, индексы `0, 1, 2`, `a[-1] = 9`, срез `a[1:3] = [7, 9]`, ошибка `a[3]`. Это позволяет выбирать подачу, сравнивая одинаковое содержание. Значения остаются в исходном списке; срез создаёт новый список. Пример не означает, что отрицательные индексы недопустимы.

Instagram-загадка объясняет, почему `bool('False')` возвращает `True`: строка непустая; `bool('')` возвращает `False`. Комикс объясняет отличие индекса от количества элементов. Приглашение показывает единую цепочку: `1 байт = 8 бит` → вопрос про 2 байта → `2 × 8 = 16 бит`. Обещаний гарантированного балла, отзывов вымышленных учеников и неподтверждённой бесплатности нет.

## Ограничения и следующий выбор

Это живые видеопробы с текстом и анимацией. Финальная голосовая дорожка и MP4 ещё не подготовлены. Фоновая музыка в Reels использует уже созданные оригинальные треки `quiet-focus` и `bit-arcade`; по умолчанию выключена. Новые треки в этой итерации не создавались.

Оформления кейсов — эскизы; они не меняют действующую коллекцию из девяти косметических предметов. Кейс по-прежнему только за уровень. Новые видео не включены в основной курс автоматически. Ни сайт, ни Instagram в рамках этой итерации не публиковались; сохранение на GitHub отдельно разрешено владельцем.

Казахские тексты подготовлены, предметные примеры проверены. Независимая модельная/редакторская вычитка и проверка носителем не подтверждены: без серверного ключа `review:kk` может собрать строки, но не выполнить запрос к редактору. Промпты ИИ не менялись.
